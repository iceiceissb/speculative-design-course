# 《请不要让我永远第一个》：指导意见拆解与重构依据

日期：2026年9月30日  
对应汇报：10月8日  
本稿状态：编剧重构与待验证假设，不是用户研究结论。

## 1. 先纠正重构方向

上一轮建议删除积分、以秀秀的成长为中心，没有充分遵循许安对这件作品的具体建议。本次保留文明积分，以礼仪系统为叙事主体，以秀秀为贯穿人物和发生局部偏离的执行者，以邱懿贞与徐月禾的关系呈现制度后果。

系统没有人形，不等于它不能成为主角。开场先展示它的规则，主要转折由它的判断引发，结尾展示它怎样记录刚刚发生的事。秀秀的成功、失误和违规则构成观众观察这个系统的连续窗口。

一句话故事：一套承诺“老人不必开口，就会得到优先”的礼仪系统，遇到一位想让老朋友先走的轮椅使用者。越体谅别人，她越被优待；护理轮椅最终降低自己的文明等级，才让两人重新决定谁先谁后。

核心追问：当礼貌必须通过系统认证，人能否拒绝被固定为“永远接受照顾的人”？

## 2. 老师要求怎样落实到作品中

| 指导意见 | 对本作品的具体要求 | 剧本中的可见证据 |
| --- | --- | --- |
| 修养即立场 | 系统与轮椅各有自认为正确的服务观 | 系统防止老人因客气失去优先；秀秀珍惜能替邱懿贞争取便利的资格 |
| 问题优先 | 不把结尾写成解决了一切的产品升级 | 一次降分解决现场；系统仍把这次服务记录为不合格 |
| 两难驱动 | 保护与自主都要有理由，且发生于具体关系 | 系统防止被迫谦让；邱懿贞希望照顾多年照顾自己的徐月禾 |
| 礼仪与礼貌 | 使用同一动作，在不同关系中展示含义变化 | “你先”在入口为陌生老人腾空间；在两位老友之间表达轮流照顾 |
| 视角清晰 | 让规则的识别、奖励、误判串起故事 | 开场规则牌、同一提示音、医院反复判定、事件归档 |
| 规则先行 | 后面的扣分脱困不能临时发明 | 开场给出90分门槛；街上不文明手势扣5；医院拒绝纠正再扣10 |
| 轮椅性格 | 有具体习惯，有局部调整，也会把反馈学过头 | 擦徽章、挡水后生气、争取朋友同行、河边面对同时发生的动作，短暂不知先帮哪一件 |
| 功能专门交代 | 小鱼投影要先让观众看懂用途，再发生异化 | 两个完整镜头：鱼在鞋边停下；人挪开，鱼散去 |
| 情绪外化 | 少写抽象的愧疚、觉醒和尊严 | 小鳍伏下、擦布停住、工具臂越过鱼线、邱懿贞将擦布放回 |
| 空间关系 | 让站位与移动表现朋友关系怎样被改写 | 并排说笑→金光把两人分成前后→降级后徐月禾先行、邱懿贞随后 |
| 镜头单元化 | 不让一个镜头同时承担规则、人物、动作和情绪 | 动作与数值变化分拍，另设功能演示、他人反应和两手全景 |
| 保留不完整 | 使人物行动有重量与犹豫 | 漏水的饵盒、翘起的胶带、错开半拍的动作、没有鱼的抄网 |
| 场景调度 | 环境变化有行程因果 | 清晨护理→赴医院→补牙后会合→下楼去钓鱼 |
| 交互呈现规则 | 后续原型呈现选择的后果，不负责替短片补完叙事 | 比较接受优先、直接拒绝、关系说明和主动降分；保留反馈与结果 |

“礼仪”与“礼貌”在这里是本作品采用的工作区分：前者指可被一致识别和执行的形式，后者指对具体处境的体谅。它不是声称两词存在唯一学术定义，也不按国籍给人物划分礼貌类型。

对应最初作业“至少三项可观察的修养”：承认局限体现在停止不适的护理、把补牙交给医生；尊重意愿体现在说明降级代价后等邱懿贞确认；纠正错误体现在撤掉不被接受的陪护申请、停止广播徐月禾的身体情况；拒绝系统纠正是第四项，其合理性留给观众争论。不能只把竖中指这一动作当成修养的全部证明。

## 3. 论文究竟提供了什么方法

阅读来源：Davidoff、Lee、Dey、Zimmerman，2007，Rapidly Exploring Application Design Through Speed Dating，UbiComp，印刷页429—446；用户提供的PDF共18页。

- PDF第3—4页（印刷页431—432）：需要验证与后续情境扮演属于不同阶段；故事板用于暴露需要与假设，不是单纯挑选最受欢迎的概念。
- PDF第5—7页（印刷页433—435）：把关键维度放进矩阵，用短情境与低保真道具进行比较。
- PDF第9—12页（印刷页437—440）：便利可能与教养、责任及人际交流发生冲突。家务带来的麻烦也可能包含人重视的互动机会；不同关系中的自动沟通会得到不同反应。
- PDF第15—16页（印刷页443—444）：矩阵服务于探索，不能提供受控实验意义上的因果鉴别或预测，也不能保证获得唯一正确的设计。

本次迁移到剧本的推论：先不要假定“少等一点”和“得到更多照护”永远有益。比较它们在不同关系中的后果，看便利是否同时剥夺了体谅别人、回报朋友的机会。

这是对论文方法的创作借用，不是论文对轮椅、老龄人群或文明积分的实证结论。

## 4. 重写之前先比较情境

下面是桌面推演，还没有邀请参与者进行情境扮演。因此不能把表中的预判当作测试结果。

固定技术：同一台轮椅、同一套老人优先制度、同一个候梯空间。变化维度：谁提出“你先”，以及接受优先会改变什么关系。

| 情境 | 优先带来的好处 | 被遮蔽的代价 | 编剧判断 |
| --- | --- | --- | --- |
| 陌生乘客为轮椅腾出空间 | 减少开口求助与被忽略 | 可能被过度注视 | 用于开场，让规则先有可信的善意 |
| 主人因旁人催促而客气让路 | 保留优先可抵抗压力 | 系统可能替人断言意愿 | 作为保护性规则的理由，不展开另一条人物线 |
| 主人等朋友洗手 | 可以节约单人出行时间 | 忽略同行愿望 | 原版冲突成立，但朋友长期离场，情感与空间关系较弱 |
| 两位老友争相让对方先走 | 保障轮椅使用者 | 把有历史的相互照顾固化为单向照护 | 选为主要场面：两人同时在场，可直接拍出关系变化 |
| 医疗急救 | 快速通行价值明确 | 其他人的等待 | 不作为主冲突，容易得到唯一答案 |
| 河边突然需要抄网 | 主动帮助能分担负荷 | 完全接管或事事请示都会打断活动 | 用于结尾，表现突发协作中的短暂忙乱，而非再次讲授自主权 |

选择第四项，不是因为它“测试获胜”，而是它更贴合本次叙事目标：相同的礼让动作，因关系与意图不同，可能需要相反的响应。

## 5. 保留、删除与重写

保留：邱懿贞、秀秀、徐月禾，补牙与钓鱼的日常行程，撑伞挡水、举报与中指，光鱼，电梯协调，文明分，双手构图，“抄网！这还用问！”和“别计时啊”。

删除：朋友长时间不在场、对四扇电梯依次到达的重复强调、“等待0秒”统计笑话。后者本身有趣，但会引出另一条指标批判，分散这次“谁有权解释礼貌”的主问题。

重写：徐月禾在医院门口与邱懿贞会合，补牙后两人同时到候梯厅；徐月禾习惯替她拿东西、留门，邱懿贞注意到朋友也累了，想这次换自己照顾她。礼遇把并肩同行拆成了固定的前后关系。

“陪护同行”只是秀秀尝试的一个可选解释，不能被写成朋友通行的必需身份。申请要征询徐月禾，徐月禾可以拒绝。它显示关系分类的局限，不新增一套强制登记制度。

## 6. 两个层次的两难

系统层：如果立即接受“你先”，可能让真实需要优先的人被客气或社会压力挤走；如果一律保留优先，又会否定当事人的具体意愿。

秀秀层：文明资格曾让邱懿贞不必每次请求让路，也是秀秀长期引以为傲的服务成果。主动降级能实现她此刻的意愿，却失去之后一段时间的额外礼遇。它不能只因自己判断就替她承担这个后果，因此在行动前说明代价，由邱懿贞确认。

邱懿贞不需要以证明自己能站立、离开轮椅或独自完成所有事情来获得自主。基本通行、照护与医疗服务从来不因积分而取消。

## 7. 必须保持透明的虚构设定

本片把现实中的善意代办、默认设置与对客套话的解释，夸张成一个没有现场直接退出渠道的示范礼遇机制。它是思辨设定，不是对现实医院规定的描述，更不是建议设计这样的系统。

普通服务可以协商顺序；90分以上启动额外的自动接待。“防止被迫礼让”协议让该次接待不能仅因口头谢绝而撤回，直到服务完成或服务设备的示范资格失效。这个不合理的边界必须前置交代，不能在高潮临时添加。

保护性规则有理由，但没有因此获得正当性的最终判决。观众可以质疑它为何没有更好的退出渠道。影片要让这个质疑成为作品的问题，而不是把漏洞包装成完美世界观。

## 8. 拍摄前应做的低成本验证

建议用打印故事板、两把椅子、一张门框纸和一张积分卡做短情境扮演。邀请轮椅使用者、老年人及有陪伴照护经验者自愿参与；若只能先请同学试演，应明确他们不是目标人群的替代样本。

每组比较三个版本：愿意接受优先；被别人客气催让；主动照顾老友。让参与者现场回应，不预告“正确选择”，不要求模仿身体障碍。轮椅角色的意义通过角色卡与座位关系交代即可。

分别追问：

1. 你在哪一刻觉得帮助变成了安排？请指出具体动作。
2. 如果换成不熟悉的人，你希望系统怎么做？
3. 你愿意用暂时失去额外礼遇换取现场决定权吗？为什么？
4. “陪护”这个标签是否让你不自在，还是你觉得无所谓？
5. 哪段规则你无法相信？在哪句话或哪个动作上不成立？

记录分歧和意外反应，不把票数变成“最佳剧情”。若多数人无需解释就能直接绕过冲突，需改规则或场景；若只能靠事后解释才明白主角是谁，应先改开场与剪辑，而非继续补台词。

## 9. 后续交互原型的边界

这次只重构剧本，不制作交互。

后续原型可让体验者在同一候梯场面选择接受礼遇、请求朋友先行、解释关系或承担降级，并看到系统如何解释行为、影响他人和改变资格。反馈应允许体验者说“不对，我不是这个意思”，展示本地记录的变化；不宣称一次输入就训练好了整座城市。

系统是否应该接受一句拒绝、要求重复确认，或保留人工协商，是可以比较的不同规则版本，不在影片结尾宣布唯一正确方案。
