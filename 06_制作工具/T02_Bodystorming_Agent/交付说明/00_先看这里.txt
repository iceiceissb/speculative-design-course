一、先解压，再运行

1. 将 ZIP 整个解压到一个普通文件夹，不要直接在压缩包内双击运行。
2. Windows 电脑需要已安装 Python 3.10 或以上版本。
   本包不包含 Python 安装程序，也不是免安装的 EXE。
3. 在解压后的“场外_Bodystorming_工作台”文件夹，双击“启动场外.cmd”。
4. 浏览器通常会自动打开。如果没有打开，查看服务窗口中的实际地址并复制到浏览器。
   默认地址是 http://127.0.0.1:8765，端口占用时会顺延。
5. 保留服务窗口。关闭窗口或按 Ctrl+C 后，网页将无法继续访问。

正常试用不需要 Node、npm、Coze 或 API 密钥。
如果提示没有 Python，请先安装 Python 3.10 或以上，再运行；没有 Python 也可以先看 design 文件夹里的截图。
如不使用 Windows，可在本目录终端执行：python3 server.py。

二、建议先试这一条流程

1. 保持右上角“演示模式”，选择“太空建造”。
2. 勾选材料，调整人数、时长、空间与规则，核对右侧活动条件确认单。
3. 点击“准备完成，生成扰动”，选一个事件。
4. 在现场引导页点选一个实际观察，再选择需要怎样的支持。
5. 生成提示后，它先停留在操作端。打开学生投屏页，人工确认后再把事件或提示展示给学生。
6. 试试“暂时留白”，并记录学生采纳、修改或拒绝提示的情况。
7. 可以保存活动方案、查看节点提示词、导入本地文字资料、导出 Markdown / JSON。

演示模式使用固定手写样例，主要用来体验流程，不会根据不同任务实时生成新事件。
真实生成需要在“模型设置”填写自己的兼容接口地址、模型名和 API 密钥；会使用该服务商的额度。
本分享包没有附带任何人的密钥、演练记录、课堂资料或运行数据库。首次启动会自动创建本机数据库。

四、当前边界

这是本机的可交互研究原型，尚未验证真实模型生成质量或教学效果。
学生投屏是同一电脑上的另一个窗口；暂不支持学生手机扫码、多设备登录或多组同步。
照片描述需要真实视觉模型；语音当前支持粘贴已有转写，没有实时摄像头或麦克风识别。
角色说明用于课堂分工，当前没有教师/学生账号权限。

比较基准是论文 §3.1.2、§3.2 与 §3.2.2，而不是此前原型的界面版本。
“论文没有详细报告某机制”不等于证明原作者的代码没有该机制。相关差异是设计延展，不是已经成立的研究创新或有效性结论。
