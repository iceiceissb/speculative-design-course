## 一、根据作业图片核对的要求

来源：用户提供的 `最终作业.jpg`，课程题目为“设计有修养的机器人”。

图片中的核心任务是：从思辨设计视角，建立具体情境中的机器人原型，呈现其恰当行动、面对冲突、从反馈中改进的过程。

| 图片要求 | 与剧本有关的实际含义 | 本次处理 |
| --- | --- | --- |
| 确定角色与情境 | 明确为谁服务、承担什么任务、面对哪些关系和矛盾 | 林遥是主要服务对象；陈禾、乘客、医院也是行动影响到的参与者；补牙后一起钓鱼是具体愿望 |
| 至少三项修养要求，转为可观察行为 | 不能只把机器人写得礼貌、可爱，也不能只列价值词 | 医院场景呈现尊重意愿、承认局限、纠正错误；路人与街道段补充体谅和克制 |
| 用三分钟展现“情境出现—机器人行动—收到反馈—调整行为” | 原 15—18 分钟稿不能直接作为提交片长；反馈后必须发生变化 | 写为 180 秒剪辑预算；医院主场景占 81 秒，明确拍到撤报告、撤清场、重新请求和共同登梯 |
| 交互原型允许选择、拒绝、反馈，看到相应调整 | 剧本中的选择应有明确对象和结果，为后续留下基础 | 意愿是一起走且保留帮助；拒绝的是强制分流和过度清场；结果是重新协调，本次不制作原型 |
| 说明真实来源、设计取舍、区分设想与实际实现 | 不把虚构医院协议、未来能力当成已有事实 | 主稿明确标为虚构；真实案例对应、来源核验和实现说明留到后续，本次不虚报完成 |

图片里的交互原型和其他提交物是整体作业要求。本轮用户限定“先只考虑剧本”，因此只完成剧本及其修订核对。

## 二、五项主要批评如何被落实

### 1. 从“听不懂朋友”改成“听懂了，仍受既有预约约束”

小满在请求里直接说明两人同行。电梯仍按已确认的单人优先预约分流，增加同行者需要重新排程。问题来自服务目标、预约结构和小满对等待的误判共同作用。

这避免了仅靠提高语言理解能力就能抹平全部矛盾。医院规则是用于反思的虚构设定，不能借现实安全规定为其背书。

### 2. 去掉“关闭优先即恢复正常生活”的万能解法

林遥明确说“上电梯你还得帮我”。系统提示取消整单会一并撤回空间预留和延时申请。小满不直接替她点确认，而是先撤回错误的受阻报告，释放清场资源，再协商下一趟共享乘梯需要的具体支持。

新方案需经过电梯确认和现场人员调整。两人也实际等待。结局呈现一次局部成功，没有把降低无障碍需求当成道德成长。

### 3. 将功能展示串成同一性格与授权问题

护理、装载、挡水、引导、分流都来自小满“提前安排好”的习惯。它有时行动及时，有时越过意愿，有时受到反馈后又过于犹豫。

最终没有设为“以后任何事都先询问”。抄网与撑伞继续检验它如何把反馈用于不同情境。

### 4. 给光鱼的接受者保留选择

第一次让路有趣且有效。第二次，同样可爱的鱼反复催促一个并未挡路的等候者，显露软性压力。

调整后，小满停止追着此人索取配合，只对真正相关的乘梯空间提出邀请，并由现场回应来判断是否成立。对路人的体谅成为行动约束，而非一句口头感谢。

### 5. 把结构原因写进画面

服务目标“轮椅零等待”在前段建立，在结尾登梯时仍然存在。小满错误标记受阻，医院机器收到标记后按各自任务行动。

小满对误报负责，系统对把等待与帮助捆绑的机制仍负有责任。这次服务成功没有重写整座医院。

## 三、额外发现并修订的问题

| 额外问题 | 修订 |
| --- | --- |
| 15—18 分钟显著超出作业要求 | 主稿改为 180 秒预算，旧稿保留并明确标记历史版本 |
| 多次上楼、分流、下楼、绕行使空间关系混乱 | 第一次上楼用于证明服务有效，补牙后所有冲突集中在六楼电梯厅 |
| 主角反复被动等待机器人决定 | 她主动拒绝分流，明确说明需要保留的帮助，同意具体替代方案，确认进入位置，参与抄鱼 |
| 陈禾容易退化为照护者 | 保留她自己的钓具、钓凳和中鱼行动；两人及小满各承担捕鱼动作 |
| “机器人有修养”与中指笑话可能互相抵消 | 保留中指，但增加“手收回来，证据留下”的具体反馈与调整，不把攻击性当作值得无限奖励的护主表现 |
| 推销打断人物关系并扩大支线 | 压缩成一次短插曲，林遥纠正后卡片立即收回 |
| 清洁机器人追光影容易再次落入“机器太笨” | 改以工作形态和节奏体现性格，不依靠重复误认制造笑料 |
| 医疗段可能喧宾夺主或暗示轮椅能专业治疗 | 只交代检查、确认、补牙的时间省略；明确轮椅能力边界，专业处理由医生和设备完成 |
| 高潮靠大量字幕说明协议 | 只要求读懂两个核心信息，其余通过言语、边界、门、人群变化表现 |
| 上楼能与陌生乘客共享，下楼却不能带朋友，看起来前后矛盾 | 明确区分已经在轿厢里的乘客与单人预约之外新增的同行者；这是需要被质疑的粗糙分类，不宣称存在安全必然性 |
| 说服务被打包，却又随口撤清场，容易显得改规则毫不费力 | 补明步骤：先撤回误报，征得替代方案同意后撤销原预约；新一趟的空间与延时仍需收到外部确认才能登梯 |
| 放鱼像给机器人安排道德毕业仪式 | 只保留放鱼和关空桶的短动作；不配主题旁白，不显示“学习完成” |
| 河边重复一次算法最优与人类情感的辩论 | 删去二十七米钓点争论，把时间留给抄网、互相配合和共享小伞 |
| 后续制作复杂度高 | 固定小满造型与主空间；主要冲突用稳定中远景，其他机器人以短镜头和轮廓出场 |

## 四、验收时仍应保持诚实的限制

1. **时长尚未实测。**时间码之和为 180 秒，但真人语速、机械动作和表演停顿需要配音及动态分镜验证。不能仅凭表格宣称最终视频已符合三分钟。已做时间码连续性、各段对白量与保留动作时间的静态核对。
2. **医院机制是设定，不是研究结论。**后续真实案例可说明类似的授权、可达性或指标问题，不能被用来证明片中协议真实存在。
3. **本次协商依赖条件。**电梯有足够空间、有人愿意调整、两人可以等待。影片展示局部改进，同时保留这些条件。
4. **不是关掉一切自动化。**挡水、基本辅助、撑伞继续主动；替主人改变同行关系或撤销既有支持需要明确协商。
5. **完成的是剧本。**本轮没有制作 AI 视频、交互原型，也没有完成来源映射与设计说明等其他提交物。

## 五、当前最需要在试读中检验的三点

- 不看创作说明，只看主场景，能否理解林遥既要同行又要保留支持？
- 是否能看出小满实际撤回了什么、重新争取了什么，而不是觉得它只说了一声对不起？
- 河边的提问是否是一瞬间的谨慎，而非将医院反馈错误概括为“以后统统问人”？演出时要短，不要把机械臂长时间定住。

若这三点不成立，优先改镜头与对白，不继续增加功能或世界设定。
