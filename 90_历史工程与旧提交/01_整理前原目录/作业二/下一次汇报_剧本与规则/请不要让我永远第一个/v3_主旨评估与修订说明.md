# v3 主旨评估与修订说明

当前主稿：[《请不要让我永远第一个》v3 三分钟完整剧本](%E8%AF%B7%E4%B8%8D%E8%A6%81%E8%AE%A9%E6%88%91%E6%B0%B8%E8%BF%9C%E7%AC%AC%E4%B8%80%E4%B8%AA_v3_%E4%B8%89%E5%88%86%E9%92%9F%E5%AE%8C%E6%95%B4%E5%89%A7%E6%9C%AC.md)

## 一、主旨有没有表达出来

**现在能够表达，但拍摄时必须保住“行为发生变化”的镜头。**

故事的核心是：机器人需要理解人想如何接受帮助，在服务主人的同时听取受影响者的回应，并承担纠正自己错误的工作。

林遥接受护理、挡水和登梯支持，也坚持与朋友同行；别人可以给她让路，也可以拒绝不必要的清场。小满必须协调这些具体需要，不能只最大化“林遥先走”。

最清楚的主旨表达由三个画面完成：

1. 四部电梯都打开，两位朋友却递不过去一顶帽子。
2. 同一个等候者留在原地，第一次被鱼反复催促，第二次鱼与机器人主动改道。
3. 最后的伞一开始就撑向两人中间，但仍需要林遥拨正。

这些画面分别表现问题、调整和有限的学习。河边的“抄网！这还用问！”保留了继续磨合的空间。

## 二、老师的要求做到什么程度

依据用户提供的“设计有修养的机器人”作业图片，**剧本层面已覆盖核心要求，整体作业尚不能宣称完成。**

| 要求 | v3 的具体证据 | 当前状态 |
| --- | --- | --- |
| 具体服务对象、任务与关系 | 林遥补牙后与陈禾钓鱼；小满同时面对主人的意愿、他人的空间与医院规则 | 已写入剧情 |
| 至少三项可观察的修养 | 尊重意愿：保留帮助并同行；承认局限：不补牙、不冒充有医院全局权限；纠正错误：撤回误报和过度清场；另有接受拒绝与克制情绪 | 已写成动作，不只是设定词 |
| 情境—行动—反馈—调整 | 申请零等待—强制分流与扩大干预—主人及等候者反馈—撤回误报、改道、重新确认支持 | 主冲突内形成完整过程 |
| 三分钟 AI 视频 | 180 秒时间预算，医院主冲突 78 秒，河边 38 秒 | 剧本已按目标设计，视频与配音未制作，时长未实测 |
| 可选择、拒绝、反馈的交互 | 拒绝分流、保留支持、拒绝不必要让路，都有不同的可观察结果 | 剧本已有可供后续设计的节点，本轮不做原型 |
| 真实依据与设想／实现区分 | 虚构医院规则、未来护理能力已标明 | 标注已做，真实案例来源映射和实现材料留待后续 |

不必把老师举例的每一种修养都塞进故事。本片先让尊重意愿、承认局限、纠正错误三项成立；其他行为支持它们，不能抢占主冲突的时长。

## 三、创新性在哪里

**有可发展的辨识度，集中在沟通方式及其变化上。**这里评价的是本作品内部的构思，不作“全球首创”的断言。

### 1. 从当天生活生成沟通形式

钓鱼安排引出装备，也引出鱼形投影。机器人与环境沟通的方式带着主人的生活痕迹，观众不用额外听一段功能介绍。

### 2. 可爱引导的两面性

鱼最初让低头看手机的人轻松察觉轮椅，后来相同外观却承担持续驱离的任务。温和外表不等于对方拥有选择。故事把这项设计的吸引力与问题一起呈现。

### 3. 别人可以改变机器人的路线

v3 增加的关键动作是：有人摇头不动，小鱼停止顶鞋；小满收拢自己外伸的装备，显示并执行另一条可用路径。投影既表达自己的行动意图，也接受别人对它的修正。

这比增加一种投影图案更值得保留，因为它改变了谁可以影响谁。

### 4. 机器人之间的合作也可能放大错误

轮椅误报、礼仪机器人清场、电梯调用备梯，各自有效执行任务，合起来却扩大了干扰。小满的修养包括撤回自己向其他机器发出的错误请求，而不只对主人说抱歉。

### 5. 学习发生在身体动作中

同一把伞，开始快速保护一个人，最后主动考虑两个人的位置。它仍然有偏差，仍需人调整；这比显示“学习完成”更能表现持续磨合。

## 四、这次继续改了什么

| v2 的不足 | v3 的修改 |
| --- | --- |
| 医院高潮像在处理订单，人物情绪偏弱 | 增加递不过去的帽子；将重排解释改成“一起乘，需要再等一趟”；用联动勾选显示服务捆绑 |
| 光鱼主要单向指挥别人 | 同一等候者再次摇头，机器人停止催促，改自己的装备与路线；用同一双鞋的重复镜头证明差异 |
| 重新登梯像请求陌生人批准自己获得帮助 | 电梯先接受无障碍支持请求，现场只协商具体的袋子与位置；是否提供必要支持不交给群众表决 |
| 小满对伙伴关系的学习不够可见 | 结尾主动把伞撑向两人中间，保留林遥微调的动作 |
| 陈禾的推销意愿由林遥代为表达 | 陈禾自己说“先别约。我就问问”，小满听取被推销者的回应 |
| 河边过于紧凑，与等待主题相冲突 | 河边由 31 秒增加到 38 秒，写入约四秒安静，并保留抄网笑话 |
| 低头族容易被演成不讲公德的群众 | 给手机使用正常的就医生活背景，不把“玩手机”当成该被规训的理由 |

## 五、仍需保持警惕的地方

**医院规则仍是最需要试看的部分。**第一次观看者应该能说出“她想和朋友一起，系统却一直催她先走”，不必复述后台规则。如果看完只觉得电梯坏了，应优先改动作因果和对白，而不是继续增加协议说明。

**三个场外笑点不能压住主冲突。**挡水、机械中指和推销可以建立性格，但推销最先可以缩短。不要为了全部保留而加速所有人的语速。

**接受拒绝有具体条件。**墙边的人确实没有阻断唯一通道，机器人能找到另一条可用路径，才能这样改道。不要让小满为了证明有修养而削减林遥所需的身体支撑或有效通行空间。

**医院的支持机制仍不理想。**这次需要林遥额外解释、接受等待，小满重新协调才能一起走。这一负担仍然存在；最终同乘证明本次调整有用，不代表制度问题已经解决。

**三分钟仍需实测。**时间码与对白量可以静态核对，情绪停顿、机械动作和镜头可读性需要动态分镜验证。本轮完成剧本修订，不把时间预算等同于成片验收。

本次静态核对结果：10 个连续段落，总计 180 秒；正文口述对白约 265 个汉字或字母数字字符（不含标点、角色名、屏幕文字及动作说明）；文件内 Markdown 链接有效。对白计数用于发现明显拥挤，不能代替演员试读。

## 六、后续试读的观察点

只给读者看正文，不先展示本说明，观察是否能回答：

1. 林遥希望机器人继续做什么，又停止什么？
2. 小满具体改了哪一个动作，而非只说了哪一句道歉？
3. 哪个人说了“不”，这个“不”有没有改变机器的行动？
4. 小满最后是否变得什么都不敢做，还是仍会主动帮助？

这些问题用于检查表达，不预先宣布观众一定能够理解。
