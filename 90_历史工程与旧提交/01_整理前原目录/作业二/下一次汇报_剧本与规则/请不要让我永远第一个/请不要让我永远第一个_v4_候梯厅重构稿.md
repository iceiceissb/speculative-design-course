# 《请不要让我永远第一个》

**导演沟通重构稿 v4｜2026-09-27**

> 本版保留为讨论记录。当前主稿是 [v5 时间寓言版完整剧本](%E8%AF%B7%E4%B8%8D%E8%A6%81%E8%AE%A9%E6%88%91%E6%B0%B8%E8%BF%9C%E7%AC%AC%E4%B8%80%E4%B8%AA_v5_%E6%97%B6%E9%97%B4%E5%AF%93%E8%A8%80%E7%89%88%E5%AE%8C%E6%95%B4%E5%89%A7%E6%9C%AC.md)，恢复了挡水序幕，并围绕“节省的时间由谁决定怎么用”增加讽刺与尾声。

> 小满为了让林遥不用等，最后让所有人都在等林遥。而林遥只是想等朋友洗个手。

本版重新组织故事，不沿用 v3 的服务订单和捆绑预约机制。全片主要发生在医院同一处候梯厅，河边只作尾声。三分钟是剪辑目标，尚未经配音与动态分镜实测。

## 一、明天可以直接讲的故事

一个老太太补完牙，坐着护理轮椅，在电梯口等朋友，准备一起去钓鱼。轮椅怕她久等，就投出小鱼引导人群让路。第一次特别好玩，大家愿意配合。可是她还没出发，轮椅就继续协调电梯、请其他机器人维持通道。最后四部电梯都开了，所有人都停下来看她，等她先走。机器人温柔地说：“不着急，大家都在等您。”老太太却说：“可我只是想等个人。”它这才发现，自己为了消除她的等待，夺走了她安静等待的可能。它要亲自撤回那些安排，继续保留她需要的上梯帮助。河边，它一时变谨慎了，问要不要帮忙，老太太立刻喊：“抄网！这还用问！”

**这部片子想问：当机器人有能力替你安排一切，你还能不能决定暂时什么也不做？**

林遥需要帮助，但也希望自己决定什么时候出发、和谁一起走。小满需要学会辨认：有些等待是困境，有些等待是人主动选择的生活。

## 二、人物与空间

**林遥，72 岁。**刚补完牙，准备去钓鱼。她不怯懦，也不需要用一段演说证明自己有主见。她今天的愿望非常小：等朋友回来，一起走。

**陈禾，74 岁。**能走路，是一起钓鱼的老朋友。已经陪林遥来到医院，暂时去洗手。她不是救援者，返回时这场小小的风波已经开始被处理。

**小满。**护理轮椅机器人，会整理仪容、取物、装载钓具、撑伞、投影以及与建筑设施协商。没有脸，靠柔性信号片、机械手与光鱼表现情绪。它努力、体贴，也有“再多准备一点就会更好”的毛病。

**折折。**扇面形礼仪机器人。收到维持通道的请求后尽职工作，扇面开合比台词更重要。它不是反派，也不是为了制造笑料而听不懂话。

**空间：**医院公共客梯厅，一侧能看见口腔科诊室的出口。四部客梯、几张座椅、正常的人流。陈禾去洗手不另拍场景。护理、补牙和钓具都从这个空间里的动作与物件交代，不回家，不上马路，不另演一段医疗过程。

**只保留一个未来设定：**小满能够向电梯与礼仪机器人发出协作请求。它为了让主人随时可以出发，逐步占用更多公共资源。优先服务确实有价值，过度之处来自它一直替主人维持“马上出发”的状态。

## 三、三分钟剧本

### 01｜00:00—00:25｜候梯厅：她要等人

镜头从林遥的手开始。

她旋开口红，小满伸出一只机械手，替她举着小镜子。

背景里，口腔科诊室的门合上。刚拿到的治疗单被她塞进包里。

她涂完，抿一下嘴，小满接过口红，收好镜子，顺手替她整理外套领口。

手机收到陈禾的语音。

**陈禾（语音）**  
我洗个手就来。等我啊。

**林遥**  
行，我在电梯这儿。

林遥按下发送，低头看一眼靠背旁的装备。

**林遥（对小满）**  
今天钓鱼，抄网可别忘了。

小满轻轻展开装备架，露出鱼竿、抄网和小鱼桶。林遥检查一下网扣，点头。

脚踏板下，一条淡黄色小鱼游出来。

林遥看它绕了一圈。

**林遥**  
鱼还没钓着，你先养上了。

小满的柔性信号片舒展开。

### 02｜00:25—00:50｜候梯厅：一次很好的帮助

人群在电梯前低头看手机。有人看挂号信息，有人回复消息。

小满轻轻响了一声，被手机通知声盖过去。

一条光鱼游到鞋边，停下。

一个人看见了，挪开半步。另一个人抬起脚，让鱼穿过去。第三个人忍不住用鞋尖逗它。

林遥沿着出现的缝隙，来到方便等候的位置。

小满向电梯发出请求，门框灯回应。最近的一部电梯打开。

小满信号片抬起，等待林遥出发。

**林遥**  
还得等她一下。

**小满**  
好，我先把路备着。

林遥没觉得有什么问题。她低头整理鱼线。

刚才逗鱼的人又看了一眼，微笑着站到旁边。

### 03｜00:50—01:30｜候梯厅：帮助开始变成催促

第一部电梯仍开着。

人流又穿过原先让出的缝隙。小满为了保证林遥随时可以出发，补上一群鱼。

鱼在脚边再次出现。有人让过一次，又被邀请再让一次。

小满增加协作请求。折折驶来，展开扇面，维持它需要的通道。

**折折**  
请让需要帮助的乘客先行。

林遥抬头。

**林遥**  
我还没走呢。

**小满**  
没关系，已经准备好了。

另一部电梯回应协作请求，也打开。小满继续寻找“更方便”的上梯条件，更多门框灯亮起。

小鱼从一条引导路径，渐渐围成一片不宜踏入的区域。

一个人刚想站回去，折折的扇面轻轻指向外侧。他停住了。

有人向林遥点头。

**乘客甲**  
您先。

另一边的人也让开一点。

**乘客乙**  
没事，您先。

四部电梯依次打开。四声悦耳的提示音。

固定远景，保持几秒。

人群退到两侧。林遥独自坐在亮亮的空地中央。鱼很漂亮，机器很礼貌。

刚才低头的人，现在都看向她。

林遥把手放到操纵杆上，又松开。

**小满（轻声）**  
不着急，大家都在等您。

安静。

林遥看着那些替自己敞开的门。

**林遥**  
可我只是想等个人。

### 04｜01:30—02:25｜候梯厅：把主动权还回来

小满的信号片停住。

它看向电梯，再看向原本可以正常通行的人群。

**小满**  
我只想着让您随时能走。

**林遥**  
让大家先走。她来了，我们再上。

她拍拍扶手。

**林遥**  
门，还是得替我留着。

小满没有关机，也没有撤走所有辅助。

它向折折发出停止清场的信号，并撤回自己多余的备梯请求。

折折的扇面收拢。

**小满（向附近乘客）**  
是我安排多了。大家正常乘梯就好。

它的声音只覆盖附近，没有再调用全厅广播。

电梯开始正常接客，人们重新走动。有人点头，有人没有注意，继续看自己的手机。

一条鱼仍在一双鞋边打转。

那个人没动。

小满让鱼退回来，收拢自己外伸的钓具架，把原先占住的一点空间还回去。对方留在原位。

林遥不用因为自己的拒绝失去座椅支撑、操纵、避障和之后登梯所需的帮助。

她重新坐定，松开刚才一直握着鱼线的手。

保留一个短暂、普通的等待：没有专用通道，没有全场注目，有脚步从身边经过。

陈禾终于回来，拎着自己的钓具。她看了一眼还未完全散去的鱼群。

**陈禾**  
怎么这么大排场？

**林遥**  
它怕我等。

陈禾看她一眼，笑。

她从包里掏出一顶备用帽，直接戴到林遥头上。林遥扶正。

下一部电梯到达。

小满发送本趟延时开门请求，门框灯回应。它收到了确认，才准备进入。

轿厢里的人调整物品，留出实际需要的位置。小满只显示一条短短的行进路径，没有要求全场清空。

**小满（对林遥）**  
现在走？

**林遥**  
走。

陈禾与林遥一起进入。轿厢里仍有其他乘客。

门在两人进入并安顿后关闭。

### 05｜02:25—02:55｜河边：它还得接着学

两人已经架好鱼竿。

细雨中，小满的小伞撑在两人中间。陈禾坐在自己的折叠钓凳上，林遥把伞稍微拨正，小满顺着微调。

水面，浮漂。留几秒安静。

陈禾的浮漂猛地沉下去。

**陈禾**  
有了！

她握紧鱼竿。

小满的机械手已伸向抄网，忽然停了半拍。

**小满**  
要帮忙吗？

**林遥**  
抄网！这还用问！

小满立刻递网，并托稳网柄。陈禾控竿，林遥找角度把鱼抄进网。三者都在忙。

水声，两个人的笑声。

镜头不在鱼的大小和去留上另开一场戏。切回两人再次坐定，网已放到一边。

**小满**  
回家吗？

**陈禾**  
再五分钟。

林遥点点头，看着水面。小满不启动返程。

停一拍。

**陈禾**  
别计时啊。

### 06｜02:55—03:00｜片名

雨声继续。

**请不要让我永远第一个**

不加主题宣言。

## 四、为什么这一次收掉很多东西

### 保留的故事主线

林遥要等朋友 → 小满提前准备 → 准备越来越多 → 全场等待林遥 → 她表达自己真正的需要 → 小满撤回过度安排并保留实际帮助 → 在钓鱼时继续磨合。

每一步都由前一步引起。主角的目标从头到尾没有变。

小满听懂了她在等朋友，仍认为可以把所有条件提前备好。它的问题在于只顾主人随时出发，忽略这些安排如何影响主人和旁人；不是因为它连“等朋友”三个字都无法理解。

### 移出本片、仍然值得留作素材的内容

- **晨间护理与自动装载：**缩成候梯时的小动作、口红收纳和装备架。完整版本适合未来扩展人物的一天。
- **汽车溅水、撑伞、中指和举报：**是一场完整、好看的独立小品。但在三分钟里，它会占用另一个场景、另一组冲突、另一轮纠错，分散本片的主要注意力。保留为人物测试短片或长片素材。
- **体验推销：**笑话成立，但不影响今天的核心冲突，暂不保留。
- **医院订单、同行名额、打包服务与整单取消：**不再承担故事动力。观众无需学习规则，直接看见过度协调如何产生压力。
- **放鱼与关空桶：**容易在尾声又引出“效率与无用”“生命与成果”的第二重主题。本版结尾集中于主动帮助和继续磨合。

本版没有否认轮椅使用者需要优先或额外支持。林遥拒绝的是在自己尚未准备出发时持续为她清场、占梯、聚集注意力；实际登梯仍由机器人辅助，延时开门仍然保留。

## 五、与“设计有修养的机器人”作业的关系

| 要求 | 本片中可观察的行为 |
| --- | --- |
| 具体角色与情境 | 护理轮椅陪主人就医后出行；在公共电梯厅面对等待、同行与其他乘客的使用需求 |
| 尊重意愿 | 林遥愿意等，小满停止把停留一律理解成应继续优化的通行问题；出发前确认具体意愿 |
| 纠正错误 | 小满亲自撤回多余备梯和清场请求，向受影响者承担说明责任，真实改变门、人流与投影 |
| 体谅他人、克制干预 | 别人不必持续让路，也不必承担林遥未要求的等待；小满收拢自己的装备，停止催促不挡路的人 |
| 从反馈中继续改进 | 医院之后短暂过度谨慎，抄网时再次被纠正；仍然提供主动帮助，不变成事事请示的机器 |
| 三分钟完整过程 | 25 秒建立人物与愿望；25 秒证明帮助有效；40 秒升级；55 秒反馈与实际调整；30 秒尾声；5 秒片名 |

本稿选择“尊重意愿、纠正错误、体谅他人并克制干预”三项作为核心修养。老师所列能力是举例，不需要为了逐项打勾而另加三个功能场景。

以上是剧本内容覆盖，不代表 AI 视频、交互原型、案例来源与设计说明等整体提交物已经完成。

## 六、给导演的三个具体讨论点

1. **高潮是否够有力？**四部电梯都打开，人人礼让，主角却越来越坐不住。希望检查这场戏能否不用解释就让观众感到压力。
2. **升级是否可信？**从提前准备到占住全厅，需要用哪些动作和节奏让观众接受？它是带讽刺意味的未来设定，不宣称现实医院会这样调度。
3. **三分钟应怎样取舍？**若试读后仍然拥挤，优先缩掉化妆对白以外的重复动作和尾声捕鱼细节，保护核心远景、普通等待及反馈后的实际调整。

本版最需要被验证的仍是第二点：过度服务的升级必须能够被画面支持，不能只靠编剧说“于是四部电梯都打开了”。这应成为明天导演指导的具体工作，而不是再讨论要添加多少功能。
