# 《请等下一班》导演讨论笔记

对应 v6 电影短片剧本，2026年9月26日。正片目标 6分30秒，含10秒片尾；这是剪辑预算，尚未通过演员试读或动态分镜实测。

## 先用这段话介绍作品

“一个坐轮椅的老人，想赶上七楼花园的夕阳，和朋友拍一张合照。她的轮椅很能干，会投影开路、跟电梯谈判。她却发现，它替自己争来的位置，是让另一个老人再次让出来的。她叫停这次安排后，机器人开始向建筑找办法，最后整块花园下来接她。可人到了面前，太阳并没有一起下来。她们还得自己决定，接下来往哪儿走。”

介绍后进入剧本或动态分镜，不先展开机器人功能清单和研究术语。

## 这一版的戏在哪里

林岚的外部目标很小：赶上光，拍一张完整合照。明天朋友出院，使这件事值得她着急，但没有把生命危险当成优先权筹码。

她的内在矛盾是：她享受有人替自己争取，也不愿公开争执。她先顺着小椅的安排走，发现获益的代价后才迟疑、按停。表演的重点是手已经落到摇杆旁，却改按停止键的半拍。不能把她演成从开场就来教育机器人的人。

小椅先用最熟悉、最容易被系统接受的请求找位置。失败后，它没有再次寻找一个好说话的人，而是抬头看向建筑。它没有修改全院制度，也没有获得无限权限；这一回，它换了一个请求对象，开始等人的回应。全片只承诺这一次行动的改变。

阿蓉有自己的节奏，会开玩笑、确认下降、决定返回、提前按快门。她不是等待被探望的背景人物。两个人的友情要先于科技命题被观众感到。

老周只需要说“我现在说不可以”。不补他的重病史，不解释他比林岚更急，也不让他用感激的眼神奖励林岚。他离开电梯厅，继续自己的生活。

## 因果与转折

1. 朋友明天出院，花园的光在移动，因此林岚急着上楼。
2. 小椅投影开路，林岚真切地获得方便，也放松了对安排的追问。
3. “空位”被揭示为老周的位置。她要在眼前的便利和他明确的拒绝之间作决定。
4. 她撤回投影，电梯带老周离开。她失去这一班，也继续失去光线；选择有即时后果。
5. 小椅向环境寻找新办法。花园下降是前一个办法被拒绝后出现的行动，不是单独插入的特效展示。
6. 花园带来朋友，却没有带来原来的光和高度。两人自己调整计划，登上花园返回七楼。
7. 夕阳仍然没赶上。结尾拍的是一次不完美的共同经历，不把庞大技术写成能够抹去全部代价的许愿机。

最后的“你也抬头”保留人与机器人之间的亲近。林岚拒绝过小椅的安排，也仍然愿意让它进入合照。

## 与第五版相比，为什么删这些

| 第五版内容 | 第六版处理 | 用处 |
| --- | --- | --- |
| 六幕、每幕两个选择 | 一条连续主线 | 让观众跟随林岚，不在每幕重新理解任务 |
| 影子远程占满空电梯 | 保留一个影子，揭示它覆盖了真实乘客的位置 | 把抽象公平问题变成同一个画面中的关系 |
| 三部电梯反复推荐 | 压成三句性格对白和一次选择 | 保留机器人社会的趣味，不重复阻碍 |
| 让路合奏 | 先带来真实愉悦，撤回请求时留下未完成的旋律 | 让帮助有吸引力，也让中断可被听见 |
| 清洁机器人借体搭桥 | 移出正片 | 它会形成另一段完整障碍，不利于6分钟主线；可留在互动demo |
| 七楼下来 | 因为不再调走另一个人，转而请求环境改变 | 奇观承担转折，并接受人物再次改变计划 |
| 结尾“不保存”的独立案例 | 放在电梯离开后的余波中 | “下次先问我”属于这次真实选择的后果；结尾留给人物动作 |

## 12个关键镜头

镜头数量是动态分镜的骨架，不是必须逐条执行的拍摄指令。常规对话可以合并在同框内完成。

| 镜号 | 景别与画面 | 承担的叙事 |
| --- | --- | --- |
| 01 | 低机位固定。投影先拐过去，真实轮椅迟几秒才到 | 建立帮助走在人前面的视觉规则 |
| 02 | 七楼近景。旧合照里林岚只剩半张脸；相机套合上 | 建立两人的旧习惯，给结尾抢拍留回声 |
| 03 | 从轮椅视线看脚、外套和人群。叶子移动，鞋尖挪开 | 让观众经历开路带来的轻松 |
| 04 | 中近景。林岚偷偷跟旋律点手指，发现被看见后收回 | 同时看见她的享受与不好意思 |
| 05 | B梯门口同框。投影先出现，老周的轮子随后进入它 | 在同一空间揭示空位从哪里来，避免先给解释性屏幕 |
| 06 | 林岚手部近景。手靠近摇杆，最后按停 | 决定由身体完成，不让台词代劳 |
| 07 | 老周与地面同框。林岚的轮廓从他脚下退走 | 取消请求有可见结果；镜头随后让他离开 |
| 08 | 门已关。林岚独自看数字，残缺的旋律结束 | 给代价和情绪留时间，长对白不占用开门时段 |
| 09 | 小椅先看另一扇门，停住，再抬头看导轨 | 它寻找办法的方向发生变化 |
| 10 | 先看抬头的人和层层下降的树影，最后才给花园大全景 | 用声影和反应建立奇观的尺度，节制展示 |
| 11 | 相机取景。两人齐了，雨棚却遮住天空 | 用画面说明目标没有被一次移动完全满足 |
| 12 | 上升的坐姿侧面镜头；尾声近景托起机器人，抢拍 | 让高度、风和关系完成收束 |

## 声音与节奏

**前半段**用电机、脚步、提示音和合奏建立逐渐顺畅的节奏。合奏只是一小句，不是整段音乐表演。林岚开始点手指时，允许观众跟着高兴。

**门开之后**减少声音。老周的停止键很小，但要听得清。别给他的拒绝配危险音效。林岚撤回投影后，旋律缺最后一个音，再自行消失。

**花园下降**让声场变大，不把音量简单推高：远处的机械低频、近处的小挂件、树叶和人群的安静共同构成尺度。不要配“奇迹发生”的满铺音乐。

**结尾**把风声带回来。开场林岚把围巾塞回领口，结尾她让它飘起来；这个动作比“我终于拥有自由”一类台词更有用。

## 制作连续性与完成度

- 正片只有一楼候梯厅、连接前厅、可升降花园三块空间，可复用第五版3D资产。相机、围巾、相纸及纸单需要补充。
- 花园导轨在第四场提出方案前进入可见环境，不能到奇观发生时突然长出来。开场七楼画面也应包含一小段导轨或连接桥。
- 下降前表现平台只有阿蓉一人，并由她确认；林岚同时同意在下方等候。这里是故事内的一次协商，不声称现实载人设备已获许可。
- 花园下降后确实可登乘返回。第五场直接承认这一点，避免观众追问“为什么不能坐它上去”。它是一次临时请求，片中没有宣布它从此取代全院电梯。
- 下降、登乘、返回的动作顺序要一致。平台未停稳时不伸连接板；返回前礼仪机器人退出，连接板收起。林岚和阿蓉始终在花园内同侧，不跨栏、不跃过高差。
- 林岚按停在门外；老周按停在轿厢内。撤回请求后，门区清空，电梯离开。“不保存”及之后的讨论放在关门后。
- 主角银灰短发、深青绿开衫、米色上衣；阿蓉用暖灰或淡褐色，与橙色礼仪机器人区分。老周沿用棕外套与纸单。
- 投影是空间请求，不用大量悬浮数据界面解释规则。观众只需读懂一次“以后也可以”和一次保存询问。
- 第五版PPT与demo目前仍是分支原型。本次完成的是线性电影剧本；改分镜、动画和汇报时应以v6为准，不把旧demo说成已经演完这版剧情。

## 交给导演讨论的三个问题

1. 林岚按停前那半拍是否足够，让人相信她真的舍不得这次机会？对白是否还可以再减？
2. 花园下降的喜剧尺度是否合适？在“真诚帮忙”和“荒诞过头”之间，哪些反应镜头最值得保留？
3. 最后选择和机器人一起入镜，能否让观众感到关系发生了变化？结尾是否需要更早停在“抬头”的动作上？

这些问题针对剧本本身，不预设导演的个人喜好或指导意见。

## 周一前优先完成

1. 两人对白试读一遍，计时；先删解释性停顿，保留门外迟疑、花园下降和上升时的呼吸。
2. 按12个关键镜头做灰模动态分镜，确认总长落在5–7分钟。若超时，优先压缩第二场人群反应与第四场设备交流，不删林岚按停的代价。
3. 带剧本阅读PDF和动态分镜，课堂先讲一句话故事，再放内容。法规与研究材料继续作备查，不占这次电影表达的主线。
