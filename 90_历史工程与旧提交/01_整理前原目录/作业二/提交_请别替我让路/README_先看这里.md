# 请别替我让路

轮椅机器人的礼貌，应该由谁付出代价？

## 提交内容

- `说明PPT_请别替我让路.pptx`：13 页，正文和研究转译表可编辑，讲述与来源写入备注。最后一页六个案例均配图，标题可点击进入来源。
- `3D交互原型/index.html`：可运行的 Three.js 交互，包含四幕分镜及案例说明。完整保留这个文件夹，双击 HTML 即可，无需联网或安装依赖。
- `研究与讲稿/`：与正式 PPT 对应的讲稿、问答、案例依据、AI 使用情况。
- `说明PPT_放映备份.pdf`：同页静态备份，适合临时无法打开 PPT 时放映。

使用 Edge 或 Chrome 打开网页。推荐电脑横屏演示；小屏可以操作，近景视角可观察人物和轮椅。3D 需要浏览器支持 WebGL。

## 建议演示顺序（约 60–90 秒）

1. 点击“开始这次相遇”。轮椅自动后退。
2. 在最初后退的几秒内点击“停，我不想退了”。观察它保留当前位置。
3. 点击“请对方让”，看行人折返到远处空间、轮椅通过、行人继续前行。
4. 点击“告诉轮椅，下次怎样做”，勾选“不要未经我同意，就带我退让”，然后确认。
5. 点击“开始下一次相遇”。轮椅留在起点等待选择，说明反馈改变了实际流程。
6. 如有时间，再体验“我这次让”，比较谁退让、谁等待。两边没有道德评分。

“重放场景”明确回到同一起点作比较；“重新开始”重置全部偏好。暂停播放与叫停动作分开。已经进入错身阶段后，停止会保持位置，可以继续原安排或结束出行。

开场的“展示条件与角色说明”可把行人条件设为“暂未回应”，之后再点击“请对方让”会保持等待。该条件属于预设脚本，不是实时感知。退出与等待不会被记作失败或不配合。

## 课堂主张与边界

本题从**身体动作**入手。虚构的服务方把“公共机器人主动让人”的规则套到载人的轮椅上，导致林岚未经征询就被带着后退。问题是公共通行便利、本人身体自主与负担分配之间的冲突。

原型实现了浏览器中的 3D 动画和规则状态变化。没有真实轮椅控制、感知、避障、语音识别、模型训练或长期记忆；没有开展目标用户研究。动画只说明故事，不验证现实运动的安全性。反馈只在本页会话内保存，刷新清空，未上传网络。

本次按作业要求选择“**分镜＋可点击原型**”的提交形式，没有制作 AI 视频。网页分镜与 PPT 使用同一个运行场景的截图。

案例来自既有 268 条混合记录中的目的性选例，关联 12 条轮椅专题核心案例。真实实验、真实运营项目、产品手册和虚构设计作品分别标识，本次不修改 PRISMA 数量。

旧版位于“提交_这一次轮椅该听谁的”，此次展示请使用本目录。
