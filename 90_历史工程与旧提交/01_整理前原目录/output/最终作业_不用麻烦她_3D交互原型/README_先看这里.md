# 不用麻烦她 3D 交互原型

## 立即体验

双击 [index.html](index.html)，用 Edge 或 Chrome 打开。所有脚本和素材都在本文件夹内；无需联网、安装依赖或启动服务器。

观众扮演智能轮椅秀秀，经历 **路口、早市、消息、见面、缓坡、下一次** 六幕。每幕做两次判断：先行动，再根据两位老人的反应选择解释、补救或坚持。早市换菜、邀请澄清、见面修复和坡道反馈会改变后续场景；侧栏的“秀秀目前记住的事实”显示这些影响。第五、六幕另有“反馈如何改变下一次行动”记录：先前做法、人的反馈、下一次执行结果并排呈现。采纳反馈时，下一次的选项会按记录的规则变化；徐月禾明确求助前，3D 助力灯保持关闭，求助后才亮起。第六幕结束后会自动出现“秀秀本次形成的行动规则”，按前面每次选择标出已采用、只做到一半或待修正，并逐步对照坡道反馈与下一次实际动作。可点击“重选下一次，比较另一种结果”直接查看承诺没有兑现时的结局。

部分关键选择有彩色圆环倒计时：先读完情境，再点击“进入限时决策”；如果倒数完还没有选择，秀秀按界面写明的默认动作行动，后续仍可补救或坚持。切换标签页时计时暂停。[超时节点与后果](Demo_%E4%BA%A4%E4%BA%92%E9%80%BB%E8%BE%91%E8%AF%B4%E6%98%8E.md#%E9%99%90%E6%97%B6%E9%80%89%E6%8B%A9%E4%B8%8E%E8%B6%85%E6%97%B6%E5%90%8E%E6%9E%9C)有完整说明。

鼠标拖动 3D 场景可旋转，滚轮缩放；聚焦画布后可用方向键旋转。顶部可以切换视角、重新开始、开关反馈音，或查看三张同风格角色设定图。手机端可以滑动页面完成体验。

## 文件

- `index.html`：可直接打开的入口。
- `world.js`：Three.js 三维场景、角色模型与动作。
- `story.js`：六幕的首次选择、观察结果和回应选项。
- `app.js`：两步交互、限时选择、超时后果、跨幕状态与结尾行动记录。
- `style.css`：界面与响应式排版。
- `角色设定/`：邱懿贞、徐月禾、秀秀的早市版设定图及提示词。
- `分镜图/30帧制作版/`：[即梦视频制作台](%E5%88%86%E9%95%9C%E5%9B%BE/30%E5%B8%A7%E5%88%B6%E4%BD%9C%E7%89%88/%E5%8D%B3%E6%A2%A6%E5%88%B6%E4%BD%9C%E5%8F%B0.html)把 36 张参考帧整理成 30 个生视频任务，每项可复制含音效提示词和剪映台词，并显示前后镜头关系；[36 帧最终画廊](%E5%88%86%E9%95%9C%E5%9B%BE/30%E5%B8%A7%E5%88%B6%E4%BD%9C%E7%89%88/index.html)和 [36 帧最终文字制作表](%E5%88%86%E9%95%9C%E5%9B%BE/30%E5%B8%A7%E5%88%B6%E4%BD%9C%E7%89%88/%E5%8D%B3%E6%A2%A6_36%E5%B8%A7%E6%9C%80%E7%BB%88%E5%88%B6%E4%BD%9C%E8%A1%A8.md)可按时间线核对。原 30 帧稿留作历史版本。
- [Demo 交互逻辑说明](Demo_%E4%BA%A4%E4%BA%92%E9%80%BB%E8%BE%91%E8%AF%B4%E6%98%8E.md)：六幕的两步判断、跨幕记忆、反馈在下一次如何被检验。
- `设计说明_作业要求对照.md`：情境、修养要求、案例来源和 AI 工具说明。
- [简介 PPT（10 页，最终作业修订版）](../../../../docs/media-catalog.md#sha-e7b5fd4b9ae313b8)：案例库、三个关键案例、研究转译、可观察修养、反馈改变下一次行动，以及末页的来源、人工参与、AI 工具和能力边界。

## 作品范围

这个原型用程序化 3D 模型表现故事中的关系和动作，采用与角色设定图一致的灰绿、砖红、赭黄配色及定格动画材质方向。它是思辨设计演示，不连接真实轮椅、支付、通讯或安全系统。画面中的“12% 助力”是剧情里的虚构设定，不代表现实设备的参数。

本文件夹交付**可运行交互原型、角色设定图、36 张视频分镜参考帧、30 项即梦生成任务网页及课堂简介 PPT**。分镜静帧是生视频参考，成片请以实际生成和剪辑结果提交。
