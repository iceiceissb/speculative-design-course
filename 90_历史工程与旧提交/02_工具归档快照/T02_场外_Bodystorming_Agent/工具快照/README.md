# 场外 · Bodystorming Agent

一个已经连接好节点的本地研究原型。输入剧本、选择突发事件、填写现场观察，即可走完“出题—选择—引导—记录”的流程。

## 直接启动

在 Windows 中双击本目录的 `启动场外.cmd`。浏览器会打开本机工作台，默认地址是 `http://127.0.0.1:8765`；端口被占用时会自动选择后续端口，实际地址显示在服务窗口。

保留服务窗口，关闭窗口或按 Ctrl+C 即可停止。需要 Python 3.10 或以上；你的工作区已检测到 Python 3.13。交付目录包含构建后的 `dist`，正常使用不需要安装 npm 包，也不需要 Coze。

## 先看一次完整流程

1. 保持右上角“演示模式”，点击“加载示例”。
2. 点击“生成 5 个突发事件”，选择一个。
3. 在现场引导页输入观察，选择“需要一点提示”，生成一次支持。
4. 将状态改为“正在自主探索”，再次运行，检查 L0。
5. 标记提示是否被采纳、修改、拒绝或尚未展示。
6. 展开节点记录，或导出 Markdown / JSON 给学姐查看。

演示模式用手写、固定的样例内容检查功能流程，不随剧本进行真实模型推理。每次演示都明确标记。真实模式报错不会自动改用这些样例。

## 接入真实模型

1. 打开“模型设置”。
2. 填 API Base URL、模型名称/服务商接入点 ID 和 API 密钥。
3. 保存后点击“测试真实连接”。该操作会发起一次真实请求。
4. 回到新建演练，右上角切换为“真实模型”，再生成。

默认预填 DeepSeek 的兼容接口地址与文档当前列出的模型 `deepseek-flash`。模型名和权限可能变化，以你服务商的控制台为准。也可以改为豆包/火山方舟或其他兼容 Chat Completions 的接口；需要其对应的密钥和模型名称，不能仅替换模型名而保留另一家的地址。

- [DeepSeek 官方接入说明](https://api-docs.deepseek.com/)
- 本程序使用 `POST {base_url}/chat/completions`（如地址已经包含此路径，则不重复追加）。
- 若服务商不支持 `response_format: json_object`，在界面取消“请求 JSON 输出模式”；节点仍会要求标准 JSON，并验证返回格式。
- 密钥仅保存在服务进程内存，不写入 SQLite、浏览器 localStorage 或导出记录。关闭服务后要重新填写；当前版本面向本机单人使用。
- 可选环境变量：`BODYSTORM_API_KEY`、`BODYSTORM_BASE_URL`、`BODYSTORM_MODEL`。未实现自动读取 `.env`。

当前环境没有可用 API 凭据，交付前无法代替你验证真实服务商的权限、余额、输出质量或视觉能力。自动测试中的模型响应是明确的测试替身，不是实际模型结果。

## 已经设计并实现的节点

```text
剧情提炼（模型）
  → 资料检索（本地程序）
  → 事件生成（模型）
  → 输出检查（程序）
  → 人工选择完整事件
  → 观察整理（人工；可选照片分析）
  → 介入决策（规则）
  → 支持检索（本地程序）
  → 分级提示（模型 / L0与待确认使用规则）
  → 记录反思（程序）
```

这是程序预先编排的 Agent 工作流。它不自主改变流程，也不声称自动判断学生的创造力或情绪。“工作流”页可以查看每个节点的职责和当前提示词；提示词文件在 `prompts` 中。

## 支持级别

| 用户确认的状态 | 本次决策 |
|---|---|
| 正在自主探索 | L0，直接返回继续探索，不调用模型 |
| 不确定是否卡住 | 待确认，询问是否需要帮助，不直接诊断 |
| 需要一点提示 | L1，一个问题或注意力提示 |
| 需要更多方向 | 有之前已展示支持时L2，否则先L1 |
| 需要一个动作起点 | L3，一个短小起点，学生决定后续 |

实际内容生成仍需人工复核。程序验证数量、字段、编号、级别和引用 ID，不保证事实正确或建议一定有用。

## 知识资料

“知识资料”页可以粘贴文本，或读取 `.txt` / `.md` 文件，并保存标题和来源。检索以中文双字和英文词的匹配及权重为依据，返回真实片段，再提供给模型。

这是可追踪的本地词法 RAG，没有向量数据库、网页爬取或联网搜索。没有匹配材料时就返回空数组。引用 ID 存在只说明来源在本次检索中，不说明来源必然支持结论。

当前不直接解析 PDF、Word 和音频文件。可以先把已核对的内容或语音转写粘贴为文本。

## 照片与语音

- 现场引导页支持上传 PNG/JPEG/WebP 照片，通过真实模型分析可见事实；需要接口与模型支持 `image_url`。结果经过你确认后才进入观察。
- 照片分析不会自动加入提示历史，也不会从单张图像推断停滞时长。照片会发送到你配置的模型服务，未在本地数据库保存原图。
- 语音目前采用“粘贴已有转写”的方式；没有实时麦克风、声纹识别或沉默计时。

## 保存、导出和边界

- 演练、资料、事件、节点输入输出、提示和反馈保存在 `data/workbench.sqlite3`。
- 草稿保存在本浏览器 localStorage；点击“新建演练”会开始新的操作，不删除已经保存的演练。
- 再次生成事件会清空当前候选、所选事件和当前提示；既往节点记录保留。
- 更换事件会清空当前提示与观察，避免串用；历史节点记录保留供核查。
- 修改情境后需要重新生成，不能沿用旧事件。
- Markdown导出包含剧本、事件、提示、反馈、反思问题和完整节点记录；JSON包含可追踪的结构化过程。
- 没有公开部署、远程多人权限、实时摄像头或自动评估学生能力。当前只监听本机回环地址。

## 修改和开发

```powershell
npm.cmd install
npm.cmd run build
python server.py --no-browser
```

后端仅使用 Python 标准库。前端使用 React、Vite、Lucide 图标；运行不依赖外部字体或 CDN，中文字体及 OFL 许可随程序提供。修改前端之后需重新构建，修改 Python 后重启服务。

测试：

```powershell
python -m unittest discover -s tests -v
```

浏览器验证脚本是 `tests/browser.mjs`，使用 Playwright Chromium；首次执行需要安装对应浏览器并设置 `PLAYWRIGHT_BROWSERS_PATH`。执行时会在 `qa` 目录生成临时测试数据。

已完成的检查与限制见 `design/verification.md`，不是教学效果验证。

## Coze 在这里的价值

Coze 可以把模型、工作流编辑、工具、会话和托管发布集中在一个服务中，适合不想维护本地代码或需要团队协作时使用。本程序把当前研究最需要的运行逻辑直接写好，让你不必手动连节点；后续代码维护、模型接入与远程部署也需要自己负责。
