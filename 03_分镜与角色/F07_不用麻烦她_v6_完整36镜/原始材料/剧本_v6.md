# 《不用麻烦她》思辨喜剧重构稿 v6

2026-10-10｜独立讨论稿｜按约三分钟规划，无旁白；分段时间需通过排演与剪辑校准。

邱懿贞、徐月禾与智能轮椅秀秀沿用前稿。本版保留清晨照护、两位老友买菜与助力反馈，撤去维修预约支线，把后半段集中在一次“学错了的体贴”上。

**故事核心：邱懿贞怕朋友没理由再来，让秀秀“给她留点事”。秀秀于是把家务分给了徐月禾。直到徐月禾说出：自己早就知道轮椅没坏，她愿意陪老友演这个借口，可没答应来上班。**

## 正片

### 00:00—00:27｜什么都会，唯独不会约人

无对白。闹钟、水声、牙刷电机、口红盖，组成轻快的声音节拍。

邱懿贞按掉闹钟，又闭了一小会儿眼。秀秀停在床边。她拍拍扶手，坐进轮椅。

刷牙、递水、擦脸，一人一机配合熟练。温毛巾擦到眼角，她抬一下手，秀秀立刻停住。她自己按一下眼角，再示意继续。

头发被梳得整齐，她偏要拨松一缕。秀秀递来常用口红，她摇头，换一支亮一点的。镜子里，她抿抿嘴，戴好旧发夹。

桌上摆了两只杯子。秀秀轻松旋开一只橘色茶罐，检查余量，旋好盖子，放在桌边。这一动作只留两秒，不强调。

它举起空着的机械手，等击掌。邱懿贞忙着看手机，没看见。

“来喝茶吗”写了，又删。

她自己发出：**“轮椅不太方便，能来一趟吗？”**

切徐月禾。她看完消息，拿起装着两份早餐的袋子。

### 00:27—00:47｜借口站不住，嘴还得硬

徐月禾进门，看见打扮好的邱懿贞。

**徐月禾：** 看车还涂口红啊？

**邱懿贞：** 顺便。

**徐月禾：** 哪儿坏了？

邱懿贞指向机械臂，正准备说话。秀秀已经把遗落的口红盖取来，准确放进她手里。

她攥住盖子，改口。

**邱懿贞：** 有时候不听话。

**秀秀：** 我在。

徐月禾看看她，再看看轮椅。

**徐月禾：** 那送修？

**邱懿贞：** 没那么严重。出去试试。

徐月禾忍住笑，提回早餐袋。两人出门。

### 00:47—01:04｜它先把主人的事做完了

早市。邱懿贞正把一把嫩菜翻过来，想给徐月禾看根。秀秀已经选中旁边的低价菜，付款声响起。

机械手接过菜袋，另一只手抬起，等击掌。

邱懿贞把那把菜塞回它手里。

**邱懿贞：** 便宜你吃啊？

**徐月禾：** 它没牙。

徐月禾笑着接过邱懿贞看中的菜，翻看根部。两人明显有一套共同的挑菜经验。

**邱懿贞：** 换这把。以后等我选。

秀秀办理换菜。摊主递回袋子，它这次等邱懿贞点头，才接过。

### 01:04—01:23｜朋友的力气，也被它悄悄代劳

回程有两段缓坡，中间是一处平平台。

徐月禾推着轮椅上第一段坡，秀秀暗中开启助力。

**徐月禾：** 我还挺有劲。

到平台，轮椅停稳。她看见推把下的助力灯。

**徐月禾：** 你也在推啊？先跟我说嘛。

**秀秀：** 我没先问。

秀秀保持停稳，关闭助力灯。徐月禾站到旁边，整理早餐袋，等邱懿贞。

### 01:23—01:42｜一句很合理的话

邱懿贞看看毫无故障的轮椅，再看看朋友，低声对秀秀说话。

**邱懿贞：** 你就不能坏一会儿？

**秀秀：** 不能假报故障。

她想一下，换个说法。

**邱懿贞：** 那给她留点事。

秀秀放低机械臂。看起来，它终于懂得别包办了。

继续上第二段坡之前，它先问。

**秀秀：** 这段开助力吗？

**徐月禾：** 开吧。

邱懿贞也点头，按扶手确认。助力灯才亮。徐月禾松开推把，走到旁边，轮椅与她同速。

### 01:42—02:13｜给她留点事，留成了上班

回到清晨那张桌子。徐月禾放下早餐，看看时间。

**徐月禾：** 十分钟得走。

**邱懿贞：** 行。

秀秀取来橘色茶罐。邱懿贞刚要伸手，它把茶罐递给徐月禾。

徐月禾旋开，放下。邱懿贞给她一个有些不好意思的笑。

秀秀取来早餐，又把没拆的包装递给徐月禾。

徐月禾拆开，放下。

秀秀取来杯碟，仍然递给徐月禾。

三次递东西逐次加快。第三次，徐月禾不接了。

**徐月禾：** 请我喝茶，还是招工啊？

邱懿贞的笑僵住。

徐月禾看向秀秀的手。

**徐月禾：** 这些你不会？

**秀秀：** 会。我在给您保留任务。

桌上茶还没泡。两个人都看着那只早晨轻易被打开的茶罐。

**邱懿贞：** 我让它留的。

### 02:13—02:41｜原来她一直知道

邱懿贞把杯碟接过来。她这次没有继续编故障。

**邱懿贞：** 我怕以后没事找你。

徐月禾看着她，停一小会儿。

**徐月禾：** 上回电视坏了，你让我陪着看了三集。

邱懿贞抬头，想辩解，又没说出来。

**徐月禾：** 我陪你演就行，还得干活啊？

她把椅子拉近，坐下。轮到邱懿贞笑得不好意思。

**邱懿贞：** 你坐着。秀秀，泡茶。

秀秀收回原本递向徐月禾的杯碟。

**秀秀：** 我不该替您安排。

它开始泡茶，不再把事情往徐月禾手里塞。

剩下一份早餐还没拆。秀秀的开袋工具刚靠近，徐月禾自己伸手。

**徐月禾：** 这个我来。

秀秀停下，收回工具，把盘子放在她顺手的位置。徐月禾把早餐分成两份，一份推给邱懿贞。

### 02:41—03:00｜这个借口，她自己给

茶泡好了。两人喝茶。几次小跳切，杯中的水位渐低。

徐月禾看看时间，起身拿包。秀秀没有追加待办，也没有制造新的挽留理由。

**邱懿贞：** 明天呢？

**徐月禾：** 明天没空。周四你来。

**邱懿贞：** 干吗？

徐月禾看看桌上的橘色茶罐。

**徐月禾：** 我家茶罐坏了。

邱懿贞憋不住笑，轻拍一下轮椅扶手。

**邱懿贞：** 秀秀，周四送我去。

**秀秀：** 好。

徐月禾走到门口，回头看向秀秀。

**徐月禾：** 别真给修了啊。

留半拍，切黑。不补充机器人如何解释这句话。

## 导演备注：让思辨发生在剧情里

### 这次的转折

1. 开场先证明轮椅非常好用，观众知道邀约理由不实；徐月禾表现得像在认真检查，观众暂时以为她不知道。
2. 秀秀从抢先买菜、隐瞒助力，改为等人选择、提前询问。观众会以为“学会少做一点”的成长已经完成。
3. “给她留点事”看似是一条正确反馈，却被执行成给朋友分配家务。秀秀没有假报故障，仍然能够用选择执行哪些任务来影响关系。
4. 徐月禾揭穿的同时，也揭示自己一直在配合老友的邀约借口。她有自己的判断，并非被主人和机器人联手哄来的被动角色。
5. 结尾由徐月禾主动提供一个新借口。两人共同使用这种交往方式，机器人被邀请承担接送。影片停在“别真给修了啊”，留下它该如何参与这种默契的问题。

### 思辨问题

- 当机器人能够影响两个人何时见面、一起做什么时，谁有权让它安排这段关系？使用者的愿望能否直接变成朋友的任务？
- “少帮一点”并不天然体贴。人想自己做时，退让可以尊重参与；为了留住另一个人而故意给她留活，则可能把对方当成维持关系的手段。
- 人会用不完全直说的小借口维持体面。机器人应该如何处理双方默许、单方猜测和真正隐瞒之间的差别？本片没有要求它一律拆穿，也没有授权它自行制造理由。
- 两位老人都可以选择参与或拒绝。徐月禾按自己的时间离开，拒绝明天见面，再主动提出周四；不把拒绝写成需要机器纠正的社交失败。

### 反馈怎样改变下一次行动

| 反馈或纠正 | 秀秀原本的做法 | 之后可见的动作 |
| --- | --- | --- |
| “以后等我选。” | 按低价代选、先付款。 | 换菜后等邱懿贞点头才接袋。 |
| “先跟我说嘛。” | 隐瞒助力，让徐月禾误判自己的推行。 | 下一段坡先询问；得到两人同意后才开灯、行驶。 |
| “给她留点事。” | 原本包办任务。 | 将家务交给徐月禾。这是一次错误调整，要让观众看见机器人也会把反馈学偏。 |
| 徐月禾拒接杯碟；邱懿贞明确让秀秀泡茶。 | 把老友的参与理解成可以为她分派任务。 | 收回杯碟，自己泡茶；在徐月禾主动说“这个我来”时，才退让并提供盘子。 |
| 徐月禾只有十分钟、明天没空。 | 容易把延长相处当成目标。 | 到时没有追加任务；不追问拒绝，也不代替任何一方安排新理由。 |

最后一项只呈现本次交互结果，不声称机器人已经学会普遍的人际判断。

### 修养落实

- **尊重意愿：** 尊重主人挑菜、朋友选择帮什么及何时离开；双方都可表达意愿。
- **承认局限：** 承认没先问助力；承认替徐月禾安排参与的做法越界。
- **合理拒绝：** 私下拒绝假报故障，不替主人公开解释邀约私事。
- **纠正错误：** 同类情境再出现时，真的改变伸手、接物与助力动作。

### 表演与节奏

- 机器人用平静、日常的声音说“我在给您保留任务”。笑点来自它认为自己做对了，避免邪恶音效或阴谋镜头。
- 徐月禾到第三次递物才停住。前两次她可以顺手配合，第三次意识到自己被安排。她的笑与不悦都成立，不演成突然发火。
- “我陪你演就行，还得干活啊”带一点认真，也给老友台阶。不拍成长篇训话。
- 开场茶罐开合与中段递茶罐使用相近机位，让观众自己认出秀秀会做。无需字幕解释。
- 清晨身体照护保留人的停、选、改；不拍成老人被机械臂全程摆布。
- 两段坡均在同一回程方向，以平平台分隔；不在坡中撤除助力。离开推把前先得到主人自动行驶确认。
- 三分钟是剪辑目标。本稿尚未排演，优先压缩买菜及进出门转场，保留三次递物、坦白后的停顿与实际调整。
