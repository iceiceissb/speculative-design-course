# 把路走通 · 晴溪两岸 v3

坐着轮椅出门办一件自己的事，遇到通行障碍时留下反馈，办完事再沿改善后的路回家。阳光、明亮的 3D 街区，Windows 电脑可直接运行。

## 启动

双击 `启动游戏.cmd`，或打开 `Build/SunnyPath.exe`。无需安装 Unity、Blender，无需联网。给别人试玩时发送完整 ZIP；EXE 需要同目录的 UnityPlayer.dll 和 SunnyPath_Data。

## 这一版的变化

- V 在“河对岸观察”和“轮椅第一人称”之间切换；镜头平滑过渡，切换不会重置位置、任务或修复进度。
- 第一人称保持坐姿眼高，可见双手、膝部、扶手和操纵器。主角自己的头部和躯干只投影，避免遮住视线；切回侧向镜头后恢复完整人物。
- 原创亚洲小女孩主角：更浅的暖肤色、黑发短辫与蝴蝶结、杏色上衣、青绿背带裤、粉色鞋，保留轮椅胎纹、轮圈、按钮和车架细节。
- 七位邻居使用三款 Quaternius 日常角色和随包骨骼动画，统一为街区配色。三位停留、四位散步，仍可和邻居聊天。
- 晴溪河道、水面细波、两岸护栏、桥梁、桥头标识、连续步道、街角小广场、导向牌和目的地前场。桥和广场实际可进入，家具及建筑具有相应碰撞。
- 三类街区保留独立任务：市集买菜、图书馆借还书、共享花园种薄荷；补充各自的市集摊位、阅读角、花圃。
- 城市地图显示河流、桥梁、路网，以及所选街区“家—三处问题—目的地”的路线预览。

## 操作

| 操作 | 河对岸视角 | 轮椅第一人称 |
| --- | --- | --- |
| V | 坐到轮椅上 | 回到河对岸 |
| A / D 或左右键 | 沿街向左 / 右 | 向左 / 右转向，可原地转向 |
| W / S 或上下键 | 纵深绕行 | 按轮椅朝向前进 / 后退 |
| 鼠标右键按住 | — | 环顾，松开恢复鼠标指针 |
| R | — | 看回轮椅正前方 |
| 滚轮 | 拉近 / 拉远 | — |
| Shift | 稍快行驶 | 稍快行驶 |

两种视角通用：E 互动、查看并确认上报、读公告、聊天、到达目的地或回家；M 城市地图；J 反馈记录；Esc 暂停 / 返回；F12 保存截图。

第一人称绕障碍时，先 A/D 转向、W 前进到外侧，再转回沿街方向。也可随时 V 切换侧向镜头观察空间。桥在街区中段，沿桥面可以到对岸的长椅旁停留。

## 完成一次出行

1. 标题页选择“逛市集 / 借本书 / 种薄荷”，Enter 开始。
2. 遇到问题按 E 查看现场照片，再按 E 或 Enter 确认提交；沿外侧绕行，继续自己的行程。
3. 到达目的地按 E。买菜选择三样食材；图书馆先还书、再找《植物图鉴》、确认借阅；花园依次领苗、种植、浇水。支持鼠标和 1/2/3，完成后 Enter。
4. 已提交的问题由游戏内城市服务处理。沿主路回家，亲自通过改善后的道路；家门前按 E，行程会记录在地图上。

六类问题：货箱占道、缺少坡道、柱口过窄、地砖翘起、车辆占道、坡道过陡。每次遇到其中三处。重复提交会合并；上报不计道德分数。

## 地图和记录

25 个街区、75 个通行地点，复用三类街区布局。完成行程后可从相邻街区继续探索，已修复的地方会保留。J 页保存实际截取的现场 PNG、地点和处理状态。

v3 使用独立本地存档 `SunnyPath_World_v3` 和 `ReportsV3`，保留 v1/v2 的存档。当前是单人本地城市，维修和政府受理属于游戏内模拟，没有多人同步或真实政府接口。
