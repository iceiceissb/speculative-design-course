# v3 画面与玩法复查

目标：两种视角可随时切换、第一人称坐姿可读、浅肤色亚洲小女孩、细化行人、河道与街区空间具有实际连通关系。

制作中发现并修正：

1. 第一人称头部网格带 .001 后缀，严格名称判断漏掉头部。改为按组名前缀判断，头和躯干保留影子，恢复侧向后完整显示。
2. 原有草地跨过河床，覆盖水面。分别建立两岸地面，保留低于步道的水面与石岸。
3. 路牌文字朝向和尺寸不适合第一人称。修正方向并统一字号、牌面比例。
4. 合并静态网格时不能删除地面碰撞。保留桥、岸、广场的 Collider，测试轮椅实际过桥与返回。
5. 原始第三方 FBX 的 Legacy 单位造成可见网格过小。保留官方原始文件，在 Blender 内重导出；将网格、骨骼与动画平移一起变成米制尺寸，Unity 保持单位缩放；按 BakeMesh 顶点复测身高与脚底。
6. 主角近景的旧前臂、刘海形状和裤脚衔接经过第二轮修整；独立头、躯干、双手和腿部用于两种镜头。

预览与流程证据保存在 QA。162 项综合流程检查和 47 项最终第一人称及行人尺寸检查通过。Windows 构建 0 错误、0 警告；最终 native_ 系列原生画面与实际按键、鼠标操作经目视复核，独立版日志无异常。初稿截图保留作开发比对，交付画面以 native_ 系列为准。模型保留可编辑 .blend，未修改任何系统 Skill。
