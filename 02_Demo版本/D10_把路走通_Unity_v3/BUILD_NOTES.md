# v3 制作与检查记录

用户要求：河对岸视角与轮椅第一人称可切换；肤色更浅的亚洲小女孩；更精细的街上行人，可选用匹配风格的现成模型；地图更考究。

在 D10 独立制作，保留 D08/v1、D09/v2。继续使用已有 Unity MCP 与 Blender MCP，未安装新工具，未调用付费生成。

## 实现

V 双视角、坐姿眼高、平滑镜头切换、按右键环顾、R 回正、按轮椅朝向前后行驶及原地转向；第一人称隐藏本人头部和躯干，保留投影及可见双手、腿部、轮椅。

新主角 9 组网格：车体、4 轮组、头部、躯干、双手、腿部。保留可编辑 Blender 部件。造型为浅暖肤色、黑发、小辫和蝴蝶结，杏色上衣、青绿背带裤和粉色鞋。

实际使用三款 Quaternius CC0 角色、七个邻居实例、Idle/Walk 骨骼动画；按本项目配色重映射不透明材质。官方来源、下载时间和授权随 CREDITS.md、Research/asset_sources.json 与原始 License.txt 保存。Kenney 只作比较，没有导入游戏。

导入检查发现原始 FBX 在本工程 Legacy 导入后，声明的 skin bounds 与实际网格不一致，导致动画播放但人物实际过小。已通过 Blender 重新整理导出，只保留两段生活动作，并在 Blender 中把网格、骨骼静止姿态及动作位移一起转换到真实米制尺寸，Unity 保持骨骼为单位缩放；用 BakeMesh 后的实际顶点检查身高、校正脚底与地面。检查覆盖真实变形尺寸，避免只看导入包围盒或动画状态。

地图增加河道、石岸、护栏、波纹水面、桥面与桥侧护栏、对岸休憩区、入口前场及街角广场。以可行驶矩形连通域约束路线，桥和广场保留真实物理地面；静态视觉合并时保留碰撞组件。第一人称可从沿街走上桥、到对岸再返回。

24 个 FBX 显式三角化，避免导入器对装饰性多边形产生不同的细分结果。路牌检查过方向、大小及可读性。保留三类街区与六类障碍。

## 检查

三类完整行程、第一人称控制、人物部件可见性、邻居动画、桥梁通行及街角广场共 162 项检查通过，耗时约 276 秒，见 QA/playtest_v3_result.json。该轮之后修正了行人 FBX 单位，另以实际顶点检查及完整第一人称往返补充验证：47 项全部通过，耗时约 102 秒，见 QA/first_person_result.json。包含七位行人的实际变形身高和脚底，第一人称上报、转向绕行、购物、沿修复后的道路回家与三张实际照片记录。

最终 Windows 构建成功，0 错误、0 警告，见 QA/build_result.json。独立版画面与实际键盘检查记录在 QA，发行包校验见 QA/release_manifest.json。

Windows 独立版自动运行通过：实际移动、三类任务与街景、三张第一人称障碍画面、邻居近景、桥梁与城市地图均已截取。实际按键检查通过 Enter、侧向 D、V 切换、第一人称 W、D 转向、按右键环顾、R 回正、V 恢复侧向、J、M 与 F12；8 张操作截图经目视复核，两次独立版日志均无运行异常，测试进程正常关闭。仅在核对进程路径及窗口焦点后发送输入；途中焦点改变时停止，重新核对后完成剩余检查。

Blender 源文件收尾时把新主角移入独立 COL-V3_Hero 集合，隐藏保留的 v2 主角与考察角色，避免打开时重叠；未改动已经实测的运行 FBX。
