# 把路走通 · 阳光街区 v2

轮椅出行、沿途上报、办完生活任务、沿着改善后的路回家。保留侧向 3D 视角和阳光配色，本版细化模型并扩展为三类街区。

## 直接玩

双击 `启动游戏.cmd`，或 `Build/SunnyPath.exe`。Windows 64 位，无需安装 Unity / Blender，无需联网。

发送给别人时使用完整 Build 文件夹或 PC 试玩 ZIP，EXE 需要同目录的 UnityPlayer.dll 与 SunnyPath_Data。

## 新增与细化

- 轮椅：胎纹、轮圈螺栓、车架连接、侧壳散热口、反光片、座椅包边与缝线、操纵屏和按钮。
- 人物：面部、眉眼、笑容、发束、手指、领口、衣缝、袖口、膝部连接和鞋带。导出时合并为六个网格组，保留四个轮组的独立转动。
- 建筑：瓦片、烟囱、檐槽、百叶窗、窗台、门牌、信箱、店铺招牌、遮阳篷与果蔬陈列。
- 独立目的地：晴日市集、梧桐图书馆、邻里共享花园。三种生活任务与相应模型、街区布置和障碍组合。
- 街道：电动滑板车、公告板、移动书架、邮筒、花叶植物、行人和小鸟。
- 反馈记录：J 打开记录页，回看真实截取的现场图片、地点与处理状态，记录保存在本机。
- 邻里事件：沿途可读公告、和邻居聊两句；修复前后会出现不同回应。
- 模型预览：购物、借阅、种植界面使用真实 3D 模型生成的物品缩略图；滚轮可拉近主镜头看细节。

24 个 FBX 资产和可编辑 Blender 源文件随完整工程保存。

## 三种出行

标题页可以直接选择“逛市集 / 借本书 / 种薄荷”。其他街区从城市地图进入。

| 目的地 | 完成的事情 | 操作 |
| --- | --- | --- |
| 晴日市集 | 挑番茄、胡萝卜和橙子，买好后回家 | 点击物品或按 1 / 2 / 3，齐备后 Enter |
| 梧桐图书馆 | 归还旧书，找到预约的《植物图鉴》，确认借阅 | 按 1 还书、2 取预约书、3 确认，再 Enter；或点击界面 |
| 共享花园 | 领取薄荷苗、种进花坛、浇水 | 按 1 / 2 / 3 依次完成，再 Enter；或点击界面 |

种植完成后，场景里的薄荷也会长起来。图书馆需要先还书再取预约书，不会通过随意点击自动完成。

## 操作

| 按键 | 操作 |
| --- | --- |
| A / D 或左右方向键 | 沿街移动 |
| W / S 或上下方向键 | 纵深绕行 |
| Shift | 稍快地行驶 |
| E | 查看并确认上报、进入目的地、读公告、聊天、回家 |
| 1 / 2 / 3、鼠标 | 目的地互动 |
| Enter | 开始、确认上报、完成当前目的地任务 |
| M | 城市地图 |
| J | 反馈记录与现场照片 |
| 鼠标滚轮 | 拉近或拉远镜头 |
| Esc | 暂停 / 返回 |
| F12 | 保存游戏截图 |

## 障碍与修复

本版共有六类问题：货箱占道、缺少坡道、柱口过窄、地砖翘起、车辆占道、坡道过陡。每趟行程遇到其中三处。

去程按 E 记录，上报后现场暂时保留障碍，可以沿外侧绕行。完成目的地任务后，已提交的问题得到模拟城市服务的处理。回家时，原地的模型与碰撞空间一起改变，可沿主路直接通过。

上报不计道德分数；重复提交合并为同一条记录。途中也可以先去办自己的事，之后补充。

## 地图与存档

25 个街区复用三类布局与任务，各自保存问题、施工结果、出行次数和邻里阅读记录。完成出行后可逐渐进入周边街区。完整改善的街区之间会在地图上连接起来。

v2 使用独立的 `SunnyPath_World_v2` 存档，旧版 v1 的文件和进度保留。照片写入本机用户数据目录的 ReportsV2；F12 游戏截图写入 Build/Screenshots。

这是单人本地 Demo。城市服务和维修在游戏内模拟；多人共建服务器与真实政府接口尚未接入。

## 工程

- Unity：`UnityProject`，版本 2022.3.62f3c1；启动场景 `Assets/Scenes/SunnyPath.unity`。
- 模型：`UnityProject/Assets/Resources/Models`。
- Blender：`Blender/sunny_assets_v002.blend`。
- 模型脚本：`Tools/refine_assets.py`，在 Blender 内运行；通过环境变量 SUNNY_V2_STAGE 选择 hero / architecture / props。
- 完整流程报告：`QA/playtest_v2_result.json`。
- Windows 构建与运行检查：`QA/build_result.json`、`QA/standalone_smoke.json`，以及 native_theme 系列截图。

PC 试玩 ZIP 仅包含运行文件和使用说明。完整工程保留在本工作区。
