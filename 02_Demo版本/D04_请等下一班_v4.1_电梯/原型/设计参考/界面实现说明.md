# 设计与实现记录

## 视觉方向

参考图：本目录“界面概念.png”。使用内置图像生成工具，生成完整的医院电梯交互界面：米白底、深青文字、暖橙强调；左侧约七成展示3D场景，右侧为叙事与行动；底部为视角控制、两位乘客状态和五步进度。

主要提示要求：中文标题《请等下一班》，完整桌面操作界面，医院电梯厅，两位老年轮椅乘坐者，林岚穿青色、另一位穿赭色；保留充足留白，不使用数据仪表盘、卡片堆叠或装饰性分数。界面文字与控件由HTML实现。

## 实现约束

- 配色：纸色 `#F4F1EA`、正文 `#172D31`、青色 `#24655F`、强调 `#A56A32`。
- 字体：正文微软雅黑/苹方，片名宋体；主画面优先，操作按钮对齐。
- 组件：页头、3D舞台、视角切换、两位乘客状态、叙事侧栏、选择按钮、五步进度、来源页。
- 网页采用静态HTML/CSS/JS，无构建或服务器依赖，以便课堂离线打开。
- 参考图只用于界面设计，不作为运行画面。为满足真实3D交互，场景采用可旋转、可移动的程序化几何，人物材质为简化风格，不能达到参考图的摄影级皮肤与布料细节。
- 情节不同阶段的文字按实际状态变化；参考图中的“查看这次怎么安排”不提前揭露后续反转，改在协调阶段提供依据展开项。

## 代码分工

`stage.js`：场景、人物模型、门与轮椅动画、视角和暂停。

`app.js`：故事状态、选择、当前同意、结果统计、偏好与下一次请求。

`style.css`：布局、字号、按钮、手机端适配。

`index.html`：页面结构、规则及来源。

## 视觉与交互检查

使用本机Edge，由Playwright打开本地文件进行检查。当前会话没有可调用的内置浏览器控制工具，因此采用此方式。检查尺寸为1536×1024（参考图原始尺寸）、1366×768和390×844。参考图与网页截图均已通过图像查看工具直接检查。

| 对照项 | 网页实现与检查结果 |
|---|---|
| 配色 | 保留米白底、深青操作、暖橙进度；降低场景曝光，避免轮椅与衣服过浅 |
| 主次布局 | 保留左侧3D、右侧操作；压缩舞台高度，使电脑首页能显示完整工具栏与页脚 |
| 字号层级 | 片名、当前情境、正文、按钮、说明分级；手机端标题与按钮均未截断 |
| 对齐与留白 | 行动按钮共用宽度与内边距，状态区两列对齐，来源页使用行列表 |
| 场景与镜头 | 两台电梯、两把轮椅、行人和工作人员；关键选择时自动拉近，修正门板滑入墙体的遮挡 |
| 交互反馈 | 场景位置、当前身份、本人同意状态和错过班次数随选择变化 |
| 响应式 | 桌面左右布局，手机上下布局；两种尺寸均未出现横向溢出 |

首屏文案核对：保留片名、情境标题、主要播放操作、视角和五步进度。将参考图中已经发生的情节改为待播放的介绍，避免画面尚未播放而正文已称结束；没有加入营销文案或无关指标。此为叙事时序调整。

有意保留的差异：参考图是高细节静态图；成品使用可执行动画的简化三维模型。轮椅零件、人物轮廓和运动是真实几何，皮肤与布料未复制为摄影级材质。原型不依赖参考图才能运行。
