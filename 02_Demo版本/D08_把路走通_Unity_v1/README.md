# 把路走通 · 阳光街区 PC Demo

Unity 2022.3 + Blender 5.2 制作的原创 3D 出行游戏原型。借鉴 Inside 的侧向移动、场景纵深和跟随镜头，采用明亮的天空、奶油色路面、珊瑚橙、湖蓝与鲜绿色。

## 直接玩

双击本目录的 `启动游戏.cmd`，或打开 `Build/SunnyPath.exe`。Windows 64 位，无需安装 Unity 或 Blender，无需联网。

如果复制给别人，请发送完整 Build 文件夹或 PC 试玩 ZIP；EXE 需要同目录的 UnityPlayer.dll 和 SunnyPath_Data。

## 操作

| 按键 | 操作 |
| --- | --- |
| A / D、左右方向键 | 沿街移动 |
| W / S、上下方向键 | 在街道纵深移动，绕过障碍 |
| E | 查看并上报附近问题、进入市集、回家 |
| 1 / 2 / 3 或鼠标点击 | 选购食材 |
| Enter | 开始游戏、确认上报、买齐后结账 |
| M | 打开或关闭城市地图 |
| Esc | 暂停或返回 |
| F12 | 保存一张游戏截图 |

## 第一趟怎么走

1. 从家出发，向右前往晴日市集。
2. 遇到货箱、台阶、过窄柱口时，按 E 查看问题，再确认提交。
3. 上报后现场暂时保持原状。按 S 往画面前侧绕行，超过障碍后按 W 回到主路。
4. 到市集按 E，选择三样食材并结账。
5. 城市服务处理已提交的反馈。沿路向左回家，原来的障碍已经清理或改造；台阶两侧有实际可走的坡道。
6. 到家按 E 保存本次行程。在城市地图上选择相邻街区，开始下一次出行。

无需为上报数量争取排名。可以先去做自己的事，漏掉的地点以后仍能记录；已上报但本次购物后才新增的反馈会留待下一趟处理。

## 本版内容

- 可操控的 3D 轮椅人物，坐姿、方向转换与滚动轮组。
- 近侧面的跟随镜头，少量纵深移动用于绕行，日光与分层街景。
- 三种有实体碰撞的障碍，以及修复后真正改变的通行空间。
- 现场画面截取、问题卡片、模拟城市服务回执、购物和返程。
- 25 个可逐步探索的街区；每个街区有独立的三处问题状态与访问记录。
- 本机存档；退出、重开和切换街区都保留修复成果。
- 中文键鼠界面、简短提示音和鸟鸣环境声，可暂停静音。

## 当前范围

这是单人本地 Demo。城市反馈、维修和复核均为游戏内模拟，没有向真实政府发送信息，也没有多人共享后台。25 个街区复用同一套道路布局与任务，通过配色、远景和独立状态区分；独特街区、更多生活任务和玩家共建同步适合作为后续版本。

## 文件

- `Build`：无需编辑器的 Windows 游戏。
- `UnityProject`：完整 Unity 工程；启动场景为 `Assets/Scenes/SunnyPath.unity`。
- `Blender/sunny_assets_v001.blend`：可编辑模型源文件。
- `UnityProject/Assets/Resources/Models`：9 个导出的 FBX 资产。
- `Tools/build_assets.py`：模型制作脚本。
- `QA`：流程检查、构建报告与游戏截图。

打开工程使用 Unity 2022.3.62f3c1。MCP 使用工作区内随工程保存的现有插件副本；不依赖另一门课程工程的相对路径。无需付费模型或生成服务。

## 存档和截图

存档由 Unity PlayerPrefs 保存在这台电脑的当前用户下，键名为 `SunnyPath_World_v1`。游戏只读写自己的进度。

独立版 F12 截图写入 `Build/Screenshots`，编辑器截图写入本目录 QA。

完整工程的验证结果见 `QA/playtest_result.json`、`QA/build_result.json`、`QA/standalone_smoke.json` 与 `QA/native_keyboard_result.json`。PC 试玩 ZIP 只包含游戏运行文件与使用说明。
