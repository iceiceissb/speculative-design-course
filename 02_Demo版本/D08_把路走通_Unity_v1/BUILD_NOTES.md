# 把路走通 · Unity Demo v1

用户授权：使用 Unity 和 Blender，制作电脑可玩的 3D Demo，侧向移动与电影式镜头参考 Inside，采用阳光、活泼的色彩。

首版目标：完整生活任务、3 处可绕行障碍、现场上报、购物、返程修复、回家、持续地图存档与相邻街区选择。

制作约定：Blender 制作风格化轮椅人物、房屋与街景资产，FBX 导入 Unity。Blender X 向前、Z 向上；Unity X 沿街、Y 向上、Z 为街道纵深。比例以米计。游戏采用近侧面透视镜头，A/D 沿街移动，W/S 在街道纵深绕行。

模型为手工程序化的风格化游戏资产。无需外部素材下载或付费生成。独立工程，不修改旧 Demo 或其他课程的 Unity 工程。

视觉：奶油白基底、珊瑚橙、湖蓝、鲜绿、暖黄，明亮天空，柔和阴影，前景植被与远景城市分层。

进度：已制作 Windows x64 独立版与完整 Unity 工程，Blender 源文件和 9 个 FBX 随工程保存。

## 已完成的实现

- 近侧面的透视跟随镜头，轮椅沿街移动及纵深绕行，坐姿人物与四组滚动轮组。
- 实体货箱、抬高路面与过窄柱口；上报不提前清除碰撞，购物后才切换修复状态。
- 两侧实际斜坡连接抬高的人行道；返程可沿主路直接通过。
- 现场截图、上报卡片、三样食材购物、回家完成行程。
- 25 个相邻街区的独立问题状态、本机存档与后续出行选择。
- 中文键鼠界面、提示音、环境鸟鸣、暂停、静音、F12 截图。

## 当前范围

本版为单人本机城市，维修与回执在游戏内模拟，没有真实政府接口或多人服务器。25 个街区复用道路与购物任务，通过场景配色、远景和独立存档区分。更丰富的街区与生活任务、联网共建可以在这个闭环上扩展。

## 使用的工具

Unity MCP（连接到本次独立 UnityProject 实例）用于导入检查、场景准备、编译检查、实际运行、截图和 Windows 构建；Blender MCP 用于创建、检查并导出模型。应用 Unity MCP orchestrator、create-3d-model 及其 modeling/materials/cameras/lighting/export 工作流。没有购买资产或调用付费模型生成。
