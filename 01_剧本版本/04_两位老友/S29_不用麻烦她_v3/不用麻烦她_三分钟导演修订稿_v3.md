# 《不用麻烦她》三分钟导演修订稿 v3

2026-10-10｜讨论稿｜目标片长约 3 分钟，无旁白。

## 人物与拍摄空间

邱懿贞，72 岁，长期使用轮椅。熟悉早市，爱漂亮，嘴上常说“顺便”。她想见徐月禾，却更容易开口请求帮忙。

徐月禾，74 岁，有自己的安排。说话直接，也会把想问的话留在输入框里。她愿意来，还愿意带早餐；能陪多久，由她自己决定。

秀秀，邱懿贞的智能轮椅。日常照护配合熟练，常按任务效率行动。它有一个小习惯：完成任务后举起机械手等击掌。它将从挑菜与推行的反馈中改变行为。

主要空间：两人各自的清晨生活角落、邱懿贞家、早市、回家路上的两段缓坡。两段坡之间有一小段平平台：前一段出现问题，平台上收到反馈，后一段立即检验调整。

## 正片

### 00:00—00:32｜两个人的早晨

没有对白。闹钟、水声、牙刷声、梳子轻碰镜框、口红盖合上，构成清晨的节奏。

邱懿贞按掉闹钟，又闭了一会儿眼。秀秀已经停在床边。她拍一下扶手，扶着床沿坐进座椅；脚落上脚踏，轮子转向洗手台。

几个短近景：秀秀帮她托稳洗漱用品、辅助刷牙，递水，温毛巾擦过脸颊。擦到眼角时她轻轻抬手，机械臂停住；她自己按一下眼角，再示意继续。动作熟练。

切徐月禾家。她在镜前整理衣领，把两份早餐分别装进餐盒，放进袋子。

切回来。秀秀梳好头发，邱懿贞看一眼，把一缕拨松。粉扑轻按脸颊。机械臂递来常用口红，她摇头，指向另一支。她涂好、抿嘴，对镜子试着笑一下，又收住。

徐月禾打开邱懿贞的聊天窗口，打出：**“今天有空吗？”** 手指停在发送键旁。

邱懿贞摆好两只杯子。她在手机上写“来喝茶吗”，想了一会儿，删掉，改成：**“今天轮椅不太方便，能来一趟吗？”** 自己按下发送。

徐月禾的手机亮起，收到这条消息。她看看已经装好的早餐，直接锁屏，拿袋子出门。她没有文字回复，原来的草稿仍留着。

邱懿贞把秀秀切到普通推行模式，屏幕只出现：**“自动行驶已暂停。”** 她看一眼镜子，把旧发夹戴上。

### 00:32—00:55｜人来了，借口不够用了

门铃响。邱懿贞还想再照一眼镜子，听见第二声，赶紧转过去。

徐月禾提着早餐进门，手机上是刚找好的维修联系电话。她先看一眼轮椅，再看邱懿贞。

**徐月禾：** 看车还涂口红啊？

**邱懿贞：** 顺便。

徐月禾把早餐放在桌上，看见两只杯子。邱懿贞下意识挪开一只，拿在手里又显得更刻意，只好放回去。徐月禾看她一眼，没说话。

**徐月禾：** 师傅电话我找到了。

秀秀提示音响。

**秀秀：** 可以恢复自动行驶了。

邱懿贞按一下扶手，先看轮椅，又看朋友。

**邱懿贞：** 秀秀，先别修。先去买菜。

徐月禾看看早餐，再看看她，拿起袋子跟上。

### 00:55—01:22｜这把菜是谁挑的

早市。摊主把菜放上秤。邱懿贞正翻另一把菜的根，秀秀已经选好低价菜，接过袋子。付款声响。

**邱懿贞：** 付了？

**秀秀：** 这把价格最低。

邱懿贞把买下的菜根翻过来，给徐月禾看。

**邱懿贞：** 你上回还嫌这把老。

**徐月禾：** 上回是你煮过头了。

邱懿贞看她一眼，把菜交回秀秀伸来等击掌的手里。

**邱懿贞：** 这回你自己煮。

两人几乎同时伸手，选中旁边的一把嫩菜。手碰到一起，互相让一下，又都没松。

秀秀看见她们选的菜，停住。

**秀秀：** 我先付了。要换这把吗？

**邱懿贞：** 换。以后先等我挑完。

摊主换菜。秀秀这次等她点头才接过袋子。镜头留在两人还没结束的拌嘴和手上的菜。

### 01:22—02:07｜坡顶，轮到另一个人嘴硬

回家。徐月禾在第一段缓坡后方握着推把。邱懿贞指路，菜袋由秀秀提着。轮椅上坡时，助力灯悄悄亮起。

**徐月禾：** 还行，我这把力气没丢。

到了平平台，轮椅停稳。徐月禾从推把下看到亮着的助力灯，和“助力 12%”的状态。

**徐月禾：** 刚才你也在推？

**秀秀：** 从坡中开始补力，没提前说明。

徐月禾松开一只手，看一眼推把。

**徐月禾：** 下回先说一声。我还以为是我有劲。

她再看向邱懿贞。

**徐月禾：** 车好好的，你怎么说不方便？

邱懿贞整理菜袋。其实袋子已经放好了，她又把袋口折了一下。手终于停住。

**邱懿贞：** 我怕叫你，你没空。

留一拍。市场的声音已经远了，只听得见袋子的轻响。

**徐月禾：** 没空我会说。

她拿出自己的手机，主动翻给邱懿贞看。输入框里，还留着早晨没发出去的：**“今天有空吗？”**

邱懿贞看完，抬头。

**邱懿贞：** 你也没发啊。

徐月禾把手机收回去。

**徐月禾：** 我还没写完。

邱懿贞看着她。徐月禾先别过脸，嘴角绷了一下。两人低头笑。

秀秀的机械手习惯性抬起。它停了停，收低，撑住两人刚才碰歪的菜袋。

### 02:07—02:24｜后一段坡

前面还有一小段上坡。镜头先给助力灯：关闭。轮椅停在坡前。

**秀秀：** 这段要开助力吗？

徐月禾看一下灯，想了想。

**徐月禾：** 开吧。买这么多菜。

她答应后，邱懿贞按扶手确认恢复自动行驶，灯才亮起。徐月禾松开推把，走到旁边。秀秀载着邱懿贞、提着菜袋，与徐月禾保持同行。

**邱懿贞：** 都是你要买的。

徐月禾顺手从袋子里抽走自己那把菜。两人继续边走边说。

### 02:24—02:45｜早餐终于吃上了

回到邱懿贞家。早晨的同一机位、同一张桌子。徐月禾打开早餐袋，两份早餐放到两只杯子旁。

邱懿贞把其中一份推向徐月禾，她又推回来。两个人换了一下，显然各自都知道对方爱吃哪份。

秀秀帮着放好菜袋，等待邱懿贞示意再退开。她倒茶，徐月禾拿起早餐。

吃了两口，徐月禾的手机提醒响。

**徐月禾：** 我一会儿还得出去。

**邱懿贞：** 去吧。

她把茶杯推近一点，让朋友喝完。两人没有急着填满这几秒。

### 02:45—03:00｜后天

门口。徐月禾拎好自己的菜，邱懿贞直接问。

**邱懿贞：** 明天来喝茶？

**徐月禾：** 明天有事。后天。

**邱懿贞：** 行。

徐月禾走了。邱懿贞回到桌边，两只杯子都喝过了，早餐袋已经空了。她收起自己的包。

手机亮起：**“后天别买那把老菜。”**

她笑，打出一个字：**“烦。”** 自己发送。

合上口红盖时的那一声“咔哒”再次响起：这次是她合上装早餐的盒盖。切黑。

## 导演工作备注（不进入正片）

- 清晨共约 32 秒，洗漱与化妆以几个关键动作建立熟练配合；保留她暂停擦脸、换口红、拨松头发的主动动作。她的生活既有便利，也有个人习惯。
- 早晨交叉剪辑让观众先知道两人都想见面。坡顶手机草稿的展示，是邱懿贞第一次知道朋友也在等她。演员在这一刻交换“被看穿”的位置。
- 徐月禾收到邀请后直接出门，不发送文字回复，使早晨草稿到坡顶仍然存在。两次展示使用同一句短文字，字幕与手机画面保持一致。
- 早市的付款是一次确实发生的抢先行动。换菜、等待确认是当场修正；坡道前一段未经说明开启助力，后一段先问、等回答、再亮灯，是另一次可见修正。
- 回家路线设为两段上坡，中间平台供三人停下交流。后一段验证反馈，空间关系在开头全景中交代清楚。
- 两份早餐与两只杯子各出现两次：准备时带着期待，吃完后留下正常相处的痕迹。口红盖与餐盒盖的声响作轻微呼应。
- 清晨快剪；门口杯子的动作、坡顶没发出的邀请各留一拍；结尾正常分别。片长 3 分钟为剪辑目标，排演时优先保留坡顶表演的停顿，可从转场与整理动作中压缩。

## 修养要求与可见行为（设计说明用）

| 要求 | 正片中可看见的行为 |
| --- | --- |
| 尊重意愿 | 清晨按她的手势停下或继续；早市等她挑好；第二段坡先问并等待；朋友能决定离开，也能拒绝明天的邀请。 |
| 承认局限 | 低价没有替代邱懿贞的挑菜经验；秀秀承认抢先付款和未说明助力，让当事人的反馈进入行动。 |
| 纠正错误 | 换回她选的菜；后一段坡助力灯在回答前关闭、回答后才亮。 |
| 如实说明 | 自动行驶只是暂停，设备故障没有被伪造；被询问时秀秀说明实际助力的起始时间。 |

清晨的洗漱、擦脸与化妆属于视频设计设想；现有 Demo 实现的是预设选择、反馈和三维动作，并未实现这些照护能力。本稿为新故事讨论版，台词和场景尚未同步到现有视频、PPT 或 Demo。
