# 《不用麻烦她》v8：创作说明与检查记录

2026-10-18｜配套记录；正片独立见[完整剧本](%E4%B8%8D%E7%94%A8%E9%BA%BB%E7%83%A6%E5%A5%B9_v8_%E5%AE%8C%E6%95%B4%E5%89%A7%E6%9C%AC.md)。

## 这次扩写的主题

秀秀先帮助邱跨过现有障碍。发现自身能力不能代表环境条件以后，它开始帮助人们把障碍留在公共视野里，再通过公共反馈、协商与建设，改变城市。

智能设备的价值贯穿始终。结尾的变化是普通轮椅也能走同样的路，秀秀的越阶机构在这段日常行程中可以安静收起。

## 行为、反馈与后果

| 要检查的内容 | 剧本中的证据 |
| --- | --- |
| 邱为何购买 | 为徐配扣子受阻，回家看广告后自行购买 |
| 购买的实际收益 | 柱口与台阶不变，秀秀带邱通过；她完整挑选扣子，也为自己买红布 |
| 错误怎样影响别人 | 本机通过被共享为入口无障碍，普通轮椅来客因此来到无法进入的店门前 |
| 秀秀如何纠正 | 撤回柱口、布店两处错误结论；保留本机通行事实及实际障碍 |
| 当天如何帮助来客 | 来客主动提出拿出整本样布，继续自己挑选，不把未来改造承诺当成当天解决方案 |
| 政府如何收到信息 | 秀秀询问邱，邱确认，地点和障碍证据进入虚构的城市无障碍服务平台，得到核查回执 |
| 个别体验如何变成公共线索 | 多位智能轮椅使用者在各自日常出行中提交；反馈显出反复受阻的点及断开的整条生活路线 |
| 未使用智能设备的人如何参与 | 纸质意见、普通轮椅居民指出楼门、工作人员入户核查，补充机器人未经过的地方 |
| 公共责任如何落地 | 街道工作人员、设计人员、店主、施工人员分别参与核查、协商、让出空间和施工 |
| 学习是否改变同类行动 | 返程柱口保留障碍；首轮新坡道本机通过后，仍保留“整改待复测” |
| 使用者意见是否改变施工结果 | 普通轮椅在门前转不过来，工作人员不结束任务，平台与门边空间继续调整 |
| 城市变化是否实际可见 | 同机位柱口通行、布店自主进入、楼门到公交与公共场所的连续路线，以及后续维护记录 |
| 人物与道具是否收束 | 裂扣带来采购动机，金扣最终缝回徐的裙子，红布成为邱自己的衣服，软尺连接裁缝生活与现场测量 |
| 朋友关系是否保有生活处境 | 徐当天仍要接孩子；结尾由孩子父亲接，给两人留出这一次相处时间 |

## 时长预算

正文十一场；文本统计为 29 句对白、239 个对白汉字。该数值不含标点与屏幕文字，不能替代实际片长。

| 场次 | 预算 | 核心画面 |
| --- | --- | --- |
| 一：原有轮椅出行 | 30 秒 | 柱口、台阶、陡坡、扣子未配成 |
| 二：广告与购买 | 20 秒 | 购买决定、几天后、猫占旧椅 |
| 三：秀秀通过 | 20 秒 | 两处真实助益及错误共享 |
| 四：布店相聚 | 20 秒 | 自己的红布、徐的金扣、半圈转身 |
| 五：来客受阻 | 30 秒 | 同一入口的事实与共享结论冲突 |
| 六：纠错与提交 | 35 秒 | 两处纠正、确认反馈、当下挑布与测量 |
| 七：多人反馈 | 20 秒 | 返程验证、日常出行、路线断点 |
| 八：现场核查 | 20 秒 | 地图、纸质意见、楼门和布店实测 |
| 九：施工与两次试用 | 35 秒 | 本机通过未结束；普通轮椅试用驱动调整 |
| 十：城市逐渐连通 | 30 秒 | 季节变化、出家门、公交与公共场所、维护 |
| 十一：再见面 | 25 秒 | 同机位柱口、红衣与舞裙、半圈舞步、片名 |
| 合计 | **285 秒／4 分 45 秒** | 预留 15 秒至五分钟上限，待排演确认 |

若排演超时，先压缩拆箱、多人反馈的重复镜头、街区扩展蒙太奇；保留第一次信息错误的后果、普通轮椅复测未通过及最终相同柱口的前后变化。

## 已完成与待制作

已做文本因果、道具、场次及预算相加检查。来客仍由街道另一侧抵达；两处原始错误均有撤回；两年跨度明确；“提交”“施工中”“本机通过”均没有提前让公共环境结论变绿。

本次没有进行演员读稿计时、轮椅机构预演、无障碍工程设计、画面生成或剪辑，也没有向任何政府平台提交信息。当前完成物是文学剧本。

后续制作先验证柱口的人体与设备外廓、越阶动作，以及布店新旧入口和转弯空间。软尺是人物行动与视觉线索，工程方案由设计人员实测与制定。

城市改造跨越两年；平台叠图用于交代多人的路线与问题，场景实拍／生成负责呈现实际变化。地图绿色结论须等核查及使用者复测完成，不能仅凭秀秀成功自动恢复。

## 能减少制作返工的现有方法

先做街口、店门和平台的简单空间预演，再扩写分镜，能提前发现“镜头看似过了、身体或脚踏其实过不去”的问题。本项目现有 Blender／本地原型能力可用于后续验证，本次未调用，不需另装插件或开启付费生成。

地图、扶手屏幕和反馈状态适合统一在后期叠加，可复用现有剪映与字幕流程，减少逐镜生成文字造成的错字与状态不一致。这里仅记录后续方法，不启动制作。

- [中国残联：贯彻实施无障碍环境建设法，促进残疾人事业全面发展，2023](https://www.cdpf.org.cn/xwzx/clyw2/f38b8b115e874a31b9b967dc03673722.htm)：提出公众参与机制及残疾人代表参与意见征询、体验试用、监督管理。用于支持居民共同参与与使用者试用的安排。

机器人自动整理障碍证据、经使用者确认后直连统一政务平台，以及剧中城市两年内的整体变化，是原创近未来设定。上述材料没有证明现实中已有这种智能轮椅联动系统；本稿也不据此承诺现实改造期限。
