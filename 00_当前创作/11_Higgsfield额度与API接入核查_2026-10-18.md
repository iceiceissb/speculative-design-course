## 购买判断

若由本聊天负责批量生成、下载、候选管理与剪辑，优先考虑火山方舟官方 Seedance 2.5 API，再交给本地 FFmpeg 与剪映草稿流程。先验证账户和一条短片，再追加全片预算；目前不能声称真实 API 生成已经接通。

若用户决定主要采用“即梦内生成 480p，再点击 8 积分变高清”，应先在即梦账户里验证这个组合。它属于另一个入口的权益，不能默认通过购买 API 或 Higgsfield 积分获得。

## 本片够不够

F11 当前计划为72个剪辑镜头，成片294秒；61个视频任务，各一个候选需要392秒源素材，另外11镜用后期图层、静帧或底板完成。F11新计划尚未导入旧试片工程。

| 一轮61条候选 | Higgsfield 估算 | 官方 API 估算 |
| --- | --- | --- |
| 全部480p | 1176 credits | 约264元 |
| 全部720p | 2744 credits | 约593元 |

因此 Plus 1000积分连全片480p首轮候选也不足；Ultra 3000积分能覆盖720p首轮，但只剩256积分，补镜余量较少。平均两轮候选时，上述用量大致翻倍。

API金额按16:9、24fps、仅文字或图片参考、没有输入视频估算；480p约0.67元/秒，720p约1.51元/秒。Higgsfield按本轮报价外推，上传参考素材后仍需重新报价。声音制作、高清处理、图片和返工另计，真实金额看实际用量与账单。[官方价格与示例](https://docs.volcengine.com/docs/ark/model-pricing?lang=en&redirect=1)

## 用户提供的“480p＋8积分变高清”

用户补充：即梦生成480p之后，页面有“变高清”按钮，约8积分，肉眼接近1080p。原小红书短链接只跳转登录页，本轮没有读到原笔记；这里记录的是用户提供的方法。

可纳入试片，但尚未核实该账户当前的8积分价格、时长限制，以及外部导入视频能否使用同一按钮。同样显示1080p，不代表手指、轮椅关节、文字和布料纹理能达到原生高分辨率的细节。动作结构错误通常需要重新生成。

节省操作：先挑选合用候选，定下切点，再为最终采用的视频处理高清。假设每条选片均收8积分，61条约需488即梦积分；实际按按钮报价计算。

API也提供480p Draft预览，再基于样片任务ID生成1080p正式视频，两步独立计费。当前官方说明正式阶段仅支持1080p，样片ID七天有效。这与即梦“8积分变高清”的收费方式不同。[官方 Draft 说明](https://docs.volcengine.com/docs/ark/seedance-2-5?lang=zh)

## Higgsfield 的优势与剪辑边界

优势是现有插件已连接，能查询费用，后续可在同一账户调用不同模型、预设与单段视频编辑功能，减少单独开发多个接口的工作。本轮没有提交生成，尚未验证当前账户付费生成权限。

官网规则规定，网页的 Unlimited 权益不覆盖普通 MCP／CLI 等外部自动调用。由聊天工具批量生成，预算应按 credits 计算。[官方积分规则](https://higgsfield.ai/creator-hub/help-center/credits/how-credits-work)

本轮读取 Higgsfield Video Editor 的安装说明：独立本地编辑插件要求 macOS。本机为 Windows，当前工具列表也没有 video_editing_open_project／create_project，不能承诺通过现有 Higgsfield 连接完成整片时间线剪辑。购买网页订阅并不能据此证明本机编辑控制可用。

本项目已有本地 FFmpeg＋剪映草稿路线；无需为剪辑额外购买 Higgsfield。Premiere 的窗口控制与原生项目交接未在本轮验证。

## 付款前后如何降低接入风险

1. 登录[火山方舟API Key管理](https://ark.volcengine.com/region:cn-beijing/apikey)，创建普通按量计费 API Key，使用本地[配置API.cmd](../06_%E5%88%B6%E4%BD%9C%E5%B7%A5%E5%85%B7/T01_AI%E8%A7%86%E9%A2%91%E5%B7%A5%E4%BD%9C%E6%B5%81/%E9%85%8D%E7%BD%AEAPI.cmd)保存。不要将Key发送到聊天。
2. 先做不创建视频任务的只读鉴权。它可以验证Key与接口访问，不能完整证明模型权限。
3. 如需余额开通，按账户控制台显示的最低要求操作，暂不购买全年或大额资源包。官方开通说明写“可用余额达到200元”，模型教程写“>200元”，以实际开通页为准。[开通说明](https://docs.volcengine.com/docs/ark/seedance-model-activation-usage-and-refund?lang=zh)
4. 经用户明确授权后，只提交一条4秒480p的连通样片，预计约2.7元生成费用。取得真实任务ID、下载视频、检查文件并生成本地剪辑交接结果。充值金额与这次任务消耗分开理解。
5. 连通与账单确认后，再试F11五个难镜头：合计39秒，480p约26元或720p约59元，均未包含重抽与高清处理。根据通过率购买后续用量。

目前没有充分证据保证“付款以后必定能生成”。现有核查已经减少网络、参数和本地后期方面的不确定性，账户与模型仍需上述真实验证。
